# Application source code

Place implementation here. Follow standard package conventions for your language/framework.

## Java / Spring Boot Convention

```text
src/
└── main/
    ├── java/
    │   └── com/example/project/
    │       ├── ProjectApplication.java
    │       ├── controller/
    │       ├── service/
    │       ├── repository/
    │       ├── model/
    │       └── config/
    └── resources/
        ├── application.yml
        └── db/migration/
```

Do not place notes or documentation in this directory.
