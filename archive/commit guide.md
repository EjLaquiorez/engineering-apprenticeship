# Phase 01 Java Foundations Commit Guide

Use these commands after completing each lesson and its matching exercise. Run the lesson command for the lesson documentation, then the exercise command for the Java exercise.

## Format

```bash
git commit -m "exercise(02-data-types): add Lesson 05 exercise"
git commit -m "docs(02-data-types): add 02.4 type conversion and casting lesson"
```

## Workflow

1. Complete the lesson documentation and matching exercise.
2. Run the exercise and check the output.
3. Stage only the lesson or exercise files being committed.
4. Copy and run the matching command above.

Example:

```bash
git add exercises/phase-01-java-foundations/02-data-types/Lesson05Exercise.java
git commit -m "exercise(02-data-types): add Lesson 05 exercise"

git add docs/lessons/phase-01-java-foundations/02-data-types/02.3-char-and-boolean.md
git commit -m "docs(02-data-types): add 02.3 char and boolean lesson"
```
