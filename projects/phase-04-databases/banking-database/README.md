# Banking Database

**Phase:** 4 — Databases  
**Status:** 🔴 Planned

## Purpose

Design and implement a banking database with proper normalization, transactions, and JDBC access.

## Requirements

- Tables: customers, accounts, transactions
- Transfer between accounts using SQL transactions
- Indexes on frequently queried columns
- ERD in `docs/entity-relationship-diagrams/`
- JDBC code with connection pooling or proper resource management
