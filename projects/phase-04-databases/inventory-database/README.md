# Inventory Database

**Phase:** 4 — Databases  
**Status:** 🔴 Planned

## Purpose

Design a normalized inventory database and access it via JDBC.

## Requirements

- Normalized schema (at least 3NF)
- Tables: products, categories, suppliers, stock_movements
- JOIN queries for reporting
- JDBC CRUD operations
