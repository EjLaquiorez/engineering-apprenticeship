# Student Management System

**Phase:** 1 — Java Foundations  
**Status:** 🔴 Planned

## Purpose

Manage student records with basic CRUD operations using procedural Java.

## Requirements

- Add, view, update, and delete student records
- Store: name, ID, age, grade
- Search students by name or ID
- Validate input (no duplicate IDs)
