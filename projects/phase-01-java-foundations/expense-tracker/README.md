# Expense Tracker

**Phase:** 1 — Java Foundations  
**Status:** 🟡 In Progress

## Purpose

Track personal income and expenses with categories using procedural Java.

The application is designed as a console program and focuses on practicing
variables, conditionals, loops, methods, arrays or collections, and basic file
I/O.

## Requirements

- Add, view, and summarize expenses
- Categorize transactions (food, transport, etc.)
- Calculate total income, total expenses, and balance
- Persist data to a file (optional stretch goal)

## Planned Workflow

1. Choose an action from the menu.
2. Enter the transaction type, amount, category, and description.
3. Review transactions or display a financial summary.
4. Save and load transactions when persistence is enabled.

## Getting Started

```powershell
Copy-Item -Recurse ../../templates/project-scaffold .
```

After scaffolding the project, compile and run the main Java class from the
project directory.
