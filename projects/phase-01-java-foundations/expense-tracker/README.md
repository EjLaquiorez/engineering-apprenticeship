# Expense Tracker

**Phase:** 1 — Java Foundations  
**Status:** 🔴 Planned

## Purpose

Track personal income and expenses with categories using procedural Java.

## Requirements

- Add, view, and summarize expenses
- Categorize transactions (food, transport, etc.)
- Calculate total income, total expenses, and balance
- Persist data to a file (optional stretch goal)
