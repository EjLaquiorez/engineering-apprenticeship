# Library Management System

A progressive Java project for applying Object-Oriented Programming (OOP) principles through requirements analysis, design, implementation, testing, and documentation.

## Project Goal

Build a library system that manages books and other library items, members, borrowing and return transactions, availability, due dates, and late fees.

## Technology

- **Language:** Java
- **Development environment:** VS Code
- **Core concepts:** Classes, objects, encapsulation, inheritance, polymorphism, abstraction, and interfaces

## Definition of Done

The project is complete when:

- The required library operations work correctly.
- Object state is encapsulated and protected by appropriate rules.
- Relationships and OOP features are justified by the actual requirements.
- The design avoids classes that take on too many unrelated responsibilities.
- Tests cover normal and invalid operations.
- The class diagram and README match the final implementation.
- Design decisions can be explained clearly.

## Working Method

For each exercise:

1. Review the objective and relevant roadmap.
2. Design a small part of the system.
3. Implement it independently.
4. Compile and test it.
5. Review feedback and fix problems.
6. Record evidence and mark the work complete before advancing.

**Guiding principle:** Understand the design before writing the code. Build a working system one justified decision at a time.
