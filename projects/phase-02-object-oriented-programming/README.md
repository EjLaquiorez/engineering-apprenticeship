## Stage 01 — Requirements

### Project Exercise 01: Problem Definition

Before writing Java code, we need to understand the problem we're solving. A good software engineer doesn't start by creating classes; they first identify the problem, users, and required outcomes.

Imagine a library currently tracks its books and borrowers manually. Records can become difficult to maintain, and staff need a reliable way to manage borrowing activities.

Your task is to write a short problem definition covering three things:

1. Problem: What problems should the Library Management System solve?
2. Users: Who will use the system? Consider library staff and people borrowing books.
3. Goals: What should those users be able to accomplish with the system?

You don't need to write a document or code yet. Reply in your own words with a few sentences or bullet points.

I'll review your requirements and ask you to refine them if necessary. Then we'll move to Project Exercise 02 — Use Cases.
