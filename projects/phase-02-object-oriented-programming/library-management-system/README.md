# Library Management System

**Phase:** 2 — Object-Oriented Programming  
**Status:** 🔴 Planned

## Purpose

Manage a library's books, members, and borrowing operations using OOP principles.

## Requirements

- Classes: Book, Member, Loan, Library
- Encapsulation: private fields with public accessors
- Inheritance or interfaces where appropriate
- Polymorphism: different member types (student, faculty) with different borrowing limits
