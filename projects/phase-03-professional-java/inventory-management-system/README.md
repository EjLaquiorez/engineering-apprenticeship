# Inventory Management System

**Phase:** 3 — Professional Java  
**Status:** 🔴 Planned

## Purpose

Manage product inventory using professional Java features: collections, streams, lambdas, exceptions, and file I/O.

## Requirements

- CRUD operations for inventory items
- Use appropriate collections (Map for lookup, List for ordering)
- Streams for filtering and aggregation
- File persistence with proper exception handling
- Input validation with meaningful error messages
