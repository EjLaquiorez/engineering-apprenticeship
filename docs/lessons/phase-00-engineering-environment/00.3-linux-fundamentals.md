# 1. Linux vs Windows

Linux and Windows are both operating systems, but they expose the system to engineers in different ways.

### Windows

Windows commonly uses:

```text
C:\
├── Users\
├── Program Files\
├── Windows\
└── ...
```

PowerShell and Command Prompt are commonly used to interact with the system.

Example:

```powershell
Get-ChildItem
Get-Location
Set-Location
```

### Linux

Linux uses a single filesystem tree beginning at:

```text
/
```

Example:

```text
/
├── home
├── etc
├── usr
├── var
├── tmp
└── ...
```

A Linux shell commonly provides commands such as:

```bash
pwd
ls
cd
mkdir
cp
mv
rm
```

### Engineering perspective

The important difference is not simply:

> "Linux has different commands."

The deeper difference is that Linux exposes many operating-system concepts through the filesystem, processes, permissions, devices, configuration files, and command-line tools.

For software engineers, Linux becomes important because many servers, containers, CI systems, cloud environments, and development environments run Linux.

# 2. Linux Filesystem Hierarchy

Linux starts at the root directory:

```text
/
```

Everything exists somewhere below `/`.

Important directories include:

```text
/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── opt
├── proc
├── root
├── run
├── sbin
├── tmp
├── usr
└── var
```

## `/home`

Contains normal users' home directories.

Example:

```text
/home/justine
```

Your personal files normally live here.

---

## `/root`

The home directory of the root user.

This is different from:

```text
/
```

`/` is the filesystem root.

`/root` is the root user's home directory.

---

## `/etc`

Contains system configuration.

Examples:

```text
/etc/hosts
/etc/passwd
/etc/ssh/
```

Think:

> `/etc` = system configuration.

---

## `/var`

Contains data that changes while the system operates.

Examples include:

```text
/var/log
/var/cache
/var/lib
```

Think:

> `/var` = variable/runtime data.

---

## `/tmp`

Temporary files.

Applications may use this directory for temporary data.

---

## `/usr`

Contains many user-space programs, libraries, and other resources.

For example:

```text
/usr/bin
/usr/lib
/usr/share
```

---

## `/dev`

Represents devices exposed to the operating system.

Examples may include:

```text
/dev/null
/dev/sda
```

---

## `/proc`

A virtual filesystem containing information about processes and the running kernel.

For example:

```text
/proc/cpuinfo
/proc/meminfo
```

This demonstrates an important Linux concept:

> Some things that look like files are interfaces to operating-system information.

# 3. Paths and Navigation

A **path** identifies the location of something in the filesystem.

There are two major types.

## Absolute path

An absolute path starts from `/`.

Example:

```bash
/home/justine/projects
```

It describes the complete location.

---

## Relative path

A relative path starts from your current directory.

Example:

```bash
projects/app
```

Its meaning depends on where you currently are.

---

## Current directory

Linux represents the current directory as:

```text
.
```

Example:

```bash
./script.sh
```

---

## Parent directory

The parent directory is represented by:

```text
..
```

Example:

```bash
cd ..
```

This moves one directory upward.

---

# 4. pwd, ls, and cd

These are fundamental navigation commands.

## `pwd`

Print working directory.

```bash
pwd
```

Example:

```text
/home/justine/projects
```

Engineering interpretation:

> "Where am I?"

---

## `ls`

Lists directory contents.

```bash
ls
```

Useful forms:

```bash
ls -l
ls -a
ls -la
```

### `-l`

Long format.

```bash
ls -l
```

Shows information such as:

- permissions
- owner
- group
- size
- modification time
- filename

### `-a`

Includes hidden files.

Linux hidden files commonly begin with:

```text
.
```

Example:

```text
.gitignore
.bashrc
```

---

## `cd`

Change directory.

```bash
cd /home/justine
```

Go to the parent:

```bash
cd ..
```

Go home:

```bash
cd ~
```

Return to the previous directory:

```bash
cd -
```
