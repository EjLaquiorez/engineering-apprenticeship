## 1. PowerShell Navigation and Paths

### Current location

```powershell
Get-Location
```

Shows the current working directory.

Example:

```text
C:\Users\ejlqr\Desktop\engineering-apprenticeship\terminal-practice
```

### Change directory

```powershell
cd terminal-practice
```

PowerShell's `cd` is an alias for `Set-Location`.

### Relative paths

A relative path starts from the current directory.

Example:

```text
docs\notes
```

### Parent directory

```powershell
cd ..
```

`..` means the parent directory.

Example:

```text
C:\Users\ejlqr\Desktop\engineering-apprenticeship\terminal-practice
```

Running:

```powershell
cd ..
```

moves to:

```text
C:\Users\ejlqr\Desktop\engineering-apprenticeship
```

### Parent followed by another directory

```powershell
cd ..\terminal-practice
```

This means:

1. Go up one directory.
2. Enter `terminal-practice`.

### Absolute paths

An absolute path identifies the complete location from the drive root.

Example:

```text
C:\Users\ejlqr\Desktop\engineering-apprenticeship\docs\notes
```

# 2. Listing Files and Directories

## `Get-ChildItem`

```powershell
Get-ChildItem
```

Lists the contents of the current directory.

Common aliases:

```powershell
dir
ls
gci
```

Example:

```powershell
Get-ChildItem
```

Output contains properties such as:

- `Mode`
- `LastWriteTime`
- `Length`
- `Name`

---

## Wildcards

### `*`

```powershell
Get-ChildItem *
```

`*` is a wildcard that broadly matches items.

### `*.txt`

```powershell
Get-ChildItem *.txt
```

Matches files whose names end in `.txt`.

Example:

```text
notes.txt
```

### `-Filter`

```powershell
Get-ChildItem -Filter *.txt
```

Filters the results to `.txt` files.

Important distinction:

```text
*             → broad wildcard
*.txt         → specific wildcard pattern
-Filter *.txt → explicit filtering parameter
```

# 3. Creating, Moving, Copying, Renaming, and Removing Items

## `New-Item`

Creates a new item.

Example:

```powershell
New-Item notes.txt
```

For a file:

```powershell
New-Item log.txt -ItemType File
```

For a directory:

```powershell
New-Item archive -ItemType Directory
```

---

## `Move-Item`

Moves an item to another location.

Example:

```powershell
Move-Item notes-copy.txt archive
```

This moves:

```text
notes-copy.txt
```

into:

```text
archive\
```

The original location no longer contains the item.

---

## `Copy-Item`

Copies an item while leaving the original in place.

Example:

```powershell
Copy-Item notes.txt notes-copy.txt
```

---

## `Remove-Item`

Removes an item.

Example:

```powershell
Remove-Item archive\notes-copy.txt
```

To remove an empty directory:

```powershell
Remove-Item archive
```

---

## `Rename-Item`

Renames an item.

Example:

```powershell
Rename-Item -Path "old.txt" -NewName "new.txt"
```

Conceptually:

```text
-Path    → where the original item is
-NewName → what the item should be called
```

# 4. Reading File Content

## `Get-Content`

Reads the contents of a file.

```powershell
Get-Content notes.txt
```

If the file doesn't exist:

```powershell
Get-Content does-not-exist.txt
```

PowerShell reports an error such as:

```text
Cannot find path ... because it does not exist.
```

`Get-Content` works with **file content**.

This is different from `Get-Item`, which retrieves the **item/object itself**.

---

## `Get-Item`

```powershell
Get-Item notes.txt
```

Retrieves the file as an object.

That allows access to properties such as:

```powershell
(Get-Item notes.txt).Length
```

The `Get-Item` part identifies the object whose property we want to inspect.

# 5. Content Commands

PowerShell follows a verb-noun naming convention.

Examples:

```text
Add-Content
Get-Content
Set-Content
```

These operate on **content**.

The important distinction is:

```text
Content → data inside a file
Item    → file, directory, or other filesystem object
```

Examples:

```powershell
Get-Content notes.txt
Get-Item notes.txt
```

# 6. Command Help and Discovery

## `Get-Command`

Finds commands available in PowerShell.

Example:

```powershell
Get-Command *Item*
```

This searches for commands containing `Item`.

It can reveal commands such as:

```text
Get-Item
New-Item
Copy-Item
Move-Item
Remove-Item
Rename-Item
Set-Item
```

---

## `Get-Help`

Gets help about a command.

Example:

```powershell
Get-Help Rename-Item -Examples
```

Useful help options include:

```powershell
Get-Help Rename-Item -Examples
Get-Help Rename-Item -Detailed
Get-Help Rename-Item -Full
Get-Help Rename-Item -Parameter Path
Get-Help Rename-Item -Online
```

If help files are unavailable locally, PowerShell may report:

```text
Get-Help cannot find the Help files for this cmdlet on this computer.
```

It may suggest:

```powershell
Update-Help
```

or:

```powershell
Get-Help Rename-Item -Online
```

# 7. Aliases

PowerShell commands can have aliases.

Example:

```powershell
Get-Alias | Where-Object Definition -eq "Get-ChildItem"
```

This showed:

```text
dir -> Get-ChildItem
gci -> Get-ChildItem
ls  -> Get-ChildItem
```

Aliases are convenient, but learning the full command names is preferable when building strong fundamentals.

# 8. Wildcards, Filtering, and Object Pipelines

PowerShell pipelines connect commands:

```powershell
Get-ChildItem | Where-Object ...
```

The pipe:

```text
|
```

passes the output objects from one command into the next command.

---

## `Where-Object`

Filters objects.

Example:

```powershell
Get-ChildItem |
    Where-Object Length -gt 100
```

Means:

> Get the items, then keep only objects whose `Length` is greater than 100.

Example result:

```text
error.txt
listing.txt
```

---

## `Sort-Object`

Sorts objects by a property.

Example:

```powershell
Get-ChildItem *.txt |
    Sort-Object Length -Descending
```

`-Descending` means largest values appear first.

---

## `Select-Object`

Selects properties or limits results.

Example:

```powershell
Get-ChildItem *.txt |
    Sort-Object Length -Descending |
    Select-Object -First 1 Name, Length
```

This means:

1. Get `.txt` files.
2. Sort by size, largest first.
3. Take the first result.
4. Display only `Name` and `Length`.

Because the largest file is first, `-First 1` finds the largest file.

---

# 9. Counting Results

A pipeline can be used to determine how many objects are returned.

Example concept:

```powershell
Get-ChildItem *.txt
```

retrieves the `.txt` files.

The result can then be counted.

The important idea is:

```text
Get objects
    ↓
Count objects
```

---

# 10. Redirection

PowerShell can redirect command output into files.

## `>`

```powershell
Get-ChildItem > listing.txt
```

Creates or **replaces** the contents of `listing.txt`.

## `>>`

```powershell
Get-ChildItem >> listing.txt
```

Creates or **appends** to `listing.txt`.

The key difference:

```text
>   → create/replace
>>  → append
```
