# Step 4 — Understand What VS Code Is Doing

When you open:

```text
engineering-apprenticeship/
```

VS Code isn't replacing Git.

Git still operates independently:

```text
             VS Code
                │
       ┌────────┼────────┐
       ↓        ↓        ↓
      Java     Git    Terminal
       │        │        │
       └────────┼────────┘
                ↓
             Project
```

The important distinction is:

> **VS Code provides an interface for development tools; it does not replace those tools.**

For example, when you click **Commit** in VS Code, VS Code is interacting with Git.

# 4. Understand the Main Java Workflow

The basic development cycle is:

```text
Write code
   ↓
Compile
   ↓
Run
   ↓
Test
   ↓
Build
```

In an IDE, many of these operations can be performed through buttons and menus.

But remember:

> **The IDE is providing an interface. Java and Gradle are still doing the actual work.**

---

# 5. Run the Java Application

Because this is a Gradle application project, you can run it through Gradle.

Open the integrated terminal:

**Terminal → New Terminal**

Make sure you're inside:

```text
gradle-practice
```

Run:

```powershell
.\gradlew.bat :app:run
```

You should see:

```text
Hello World!
```

The important part is:

```text
:app:run
```

You're telling Gradle:

> Run the `run` task belonging to the `app` project.

---

# 6. Run the Tests

Now run:

```powershell
.\gradlew.bat :app:test
```

You should get something similar to:

```text
BUILD SUCCESSFUL
```

Your test is located at:

```text
app/src/test/java/org/example/AppTest.java
```

The test currently checks:

```java
assertNotNull(classUnderTest.getGreeting());
```

So the test verifies that the application produces a greeting rather than `null`.

---

# 7. Run the Build

Now:

```powershell
.\gradlew.bat build
```

Gradle will perform the necessary tasks to build the application.

Conceptually:

```text
build
 │
 ├── compile Java
 │
 ├── compile tests
 │
 ├── run tests
 │
 └── package application
```

The exact task graph is determined by Gradle.

   ↓
