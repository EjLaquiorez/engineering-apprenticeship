# 11. Terminal vs IDE

This distinction is important.

### Terminal

You explicitly type:

```powershell
.\gradlew.bat :app:test
```

### IDE

You select:

```text
Gradle
  ↓
app
  ↓
Tasks
  ↓
test
```

The result is conceptually the same:

```text
          ┌── Terminal ──┐
          │              │
          ↓              ↓
        Gradle ←──────── VS Code
          │
          ↓
        Tasks
```

VS Code provides a convenient interface.

# 12. Why Developers Still Use the Terminal

Even when an IDE provides Maven and Gradle integration, developers still need the terminal.

Why?

### Reason 1 — Reproducibility

You can explicitly see what command you're running.

```powershell
.\gradlew.bat build
```

### Reason 2 — Troubleshooting

When something goes wrong, terminal output often gives detailed information.

### Reason 3 — CI/CD

Build servers commonly execute commands rather than relying on your IDE.

For example:

```text
Developer machine
      ↓
.\gradlew.bat build
      ↓
CI server
      ↓
.\gradlew.bat build
```

### Reason 4 — IDE independence

Your knowledge shouldn't depend on one particular IDE.

# 13. The Professional Mental Model

This is the important concept for Phase 00:

```text
             Developer
                 │
                 ↓
              VS Code
                 │
       ┌─────────┼─────────┐
       ↓         ↓         ↓
      Java      Git      Build Tool
                           │
                     ┌─────┴─────┐
                     ↓           ↓
                   Maven       Gradle
```

VS Code is the **workspace/interface**.

Git, Java, Maven, and Gradle remain **independent engineering tools**.
