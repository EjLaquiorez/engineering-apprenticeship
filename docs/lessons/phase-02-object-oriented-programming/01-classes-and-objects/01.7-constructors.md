# 1. Why Do Constructors Exist?

Remember what you've been doing so far:

```java
class Student {
    String name;
    int age;
}
```

Then in `main()`:

```java
Student student = new Student();

student.name = "Justine";
student.age = 20;
```

This works.

But notice something:

```java
Student student = new Student();
```

creates the object first.

Then you have to separately initialize it:

```java
student.name = "Justine";
student.age = 20;
```

Imagine creating 100 students.

You'd have to repeatedly create the object and manually assign all its fields.

A **constructor** gives us a way to initialize an object **when the object is created**.

Conceptually:

```text
Create object
     ↓
Constructor runs
     ↓
Object starts with initial state
```

---

# 2. What Is a Constructor?

A constructor is a special part of a class that runs automatically when you create an object with `new`.

For example:

```java
class Student {

    Student() {
        System.out.println("Student created!");
    }
}
```

Then:

```java
Student student = new Student();
```

When this executes, the constructor runs automatically:

```text
Student created!
```

You don't call it like a normal method.

You don't write:

```java
student.Student();
```

Instead, it runs because of:

```java
new Student();
```

---

# 3. Constructor Naming Rule

There is one very important rule:

> **A constructor must have exactly the same name as the class.**

Class:

```java
class Student {
```

Constructor:

```java
Student() {
```

Notice:

```text
Class       → Student
Constructor → Student
```

They have the same name.

---

# 4. Constructor Has No Return Type

Compare a constructor with a method.

### Constructor

```java
Student() {
    System.out.println("Created");
}
```

### Method

```java
void displayInfo() {
    System.out.println("Student");
}
```

The method has:

```java
void
```

The constructor has **no return type**.

Not even `void`.

This is wrong:

```java
void Student() {
}
```

That is actually a method named `Student`, **not a constructor**.

---

# 5. The Constructor Runs Automatically

Consider:

```java
class Dog {

    Dog() {
        System.out.println("Dog constructor running");
    }
}
```

And:

```java
Dog dog = new Dog();
```

Think about the sequence:

```text
Dog dog
   ↓
new Dog()
   ↓
Dog() constructor runs
   ↓
Dog object is created/initialized
```

You don't manually call the constructor.
