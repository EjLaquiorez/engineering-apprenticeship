## 1. What is a field?

You've already been using fields:

```java
class Dog {
    String color;
    String breed;
}
```

Here:

```text
color → field
breed → field
```

A **field** is a variable that belongs to an object/class and represents the object's **data or state**.

For example:

```text
dog1
├── color = "Brown"
└── breed = "Labrador"
```

The values stored in those fields describe the **state** of `dog1`.

---

## 2. Fields belong to each object

This is important.

When you create:

```java
Dog dog1 = new Dog();
Dog dog2 = new Dog();
```

you get two separate objects.

Even though both came from the same class:

```text
Dog class
   │
   ├── dog1
   │    ├── color
   │    └── breed
   │
   └── dog2
        ├── color
        └── breed
```

Changing `dog1` does **not** automatically change `dog2`.

For example:

```java
dog1.color = "Brown";
dog2.color = "Black";
```

Now:

```text
dog1.color → Brown
dog2.color → Black
```

That's because each object has its own instance fields.

---

# 3. Fields can have different data types

A class can contain different types of data:

```java
class Student {
    String name;
    int age;
    double grade;
    boolean enrolled;
}
```

So:

```text
name      → String
age       → int
grade     → double
enrolled  → boolean
```

The field's type determines what kind of value it can store.
