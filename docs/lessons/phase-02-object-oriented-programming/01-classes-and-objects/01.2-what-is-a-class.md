# Topic 1 — Classes & Objects

### Lesson 02 — What Is a Class?

**Goal:** Understand a class as the blueprint used to create objects.

Before I explain it, let's test your intuition.

Imagine we're building a `Car` program.

We want every car to potentially have:

```text
brand
color
speed

start()
accelerate()
brake()
stop()
```

Now imagine we need **three cars**:

```text
Toyota
Honda
Ford
```

### Question

Would it make sense to write a completely separate definition of `brand`, `color`, `speed`, `start()`, `accelerate()`, etc. for every single car?

Or would it be better to create **one blueprint** describing what a Car has and does, then create individual cars from that blueprint?

**Tell me which approach you think makes more sense and why.**
