# Lesson 01 — What Is Object-Oriented Programming?

You already know how to write procedural Java:

```java
String name = "John";
int age = 25;

System.out.println(name);
System.out.println(age);
```

Here, we're mostly thinking about **data and instructions separately**.

OOP gives us another way to organize programs:

> **Put related data and behavior together into objects.**

For example, imagine a student.

A student has **data**:

```text
name
age
studentId
course
```

A student can also perform or have **behaviors**:

```text
study()
attendClass()
displayInformation()
```

Instead of thinking about these as unrelated pieces, OOP lets us model a **Student** as an object.

Conceptually:

```text
Student
│
├── Data
│   ├── name
│   ├── age
│   └── studentId
│
└── Behavior
    ├── study()
    └── displayInformation()
```

This is the fundamental idea we'll build on throughout Phase 02.

---

## The four major OOP ideas we'll eventually study

You don't need to memorize these yet. We'll learn each one properly.

### 1. Encapsulation

Keeping an object's data and behavior together while controlling access to its data.

### 2. Inheritance

Allowing one class to derive from another class.

```text
Animal
   ↓
 Dog
```

### 3. Polymorphism

Allowing objects of different types to be handled through a common interface or parent type.

### 4. Abstraction

Focusing on what an object does while hiding unnecessary implementation details.
