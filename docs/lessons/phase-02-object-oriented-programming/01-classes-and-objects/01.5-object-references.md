# Lesson 05 — Object References

### Core idea

When you write:

```java
Dog dog1 = new Dog();
```

there are actually two concepts involved:

```text
Dog dog1 = new Dog();
    ↑         ↑
 reference   object
 variable
```

`new Dog()` creates the **object**.

`dog1` is a **reference variable** that refers to that object.

Think:

```text
dog1 ───────────→ Dog object
```

The variable doesn't contain the entire object in the way an `int` variable contains `10`. It refers to the object.

We'll explore that through the three official exercises.

## Exercise 05A — Reference Experiment

Create:

```text
Exercise05A.java
```

Create a simple `Dog` class with:

```java
String name;
```

Then create **two separate Dog objects**:

```text
dog1
dog2
```

Give them different names.

Then print their names.

The goal is to observe:

```text
dog1 ─────→ Dog object 1
              name = ...

dog2 ─────→ Dog object 2
              name = ...
```

**Don't worry about shared references or `null` yet.** Those are Exercises 05B and 05C.

Write `Exercise05A.java` yourself and send it here.
