## 1. Multiple Constructors

So far, you've created a class with **one constructor**:

```java
class Book {
    String title;
    int pages;

    Book(String title, int pages) {
        this.title = title;
        this.pages = pages;
    }
}
```

You can create a book like:

```java
Book book = new Book("Java Basics", 300);
```

But what if you want to allow this too?

```java
Book book = new Book("Unknown", 0);
```

You can create **more than one constructor** inside the same class.

```java
class Book {
    String title;
    int pages;

    Book() {
        title = "Unknown";
        pages = 0;
    }

    Book(String title, int pages) {
        this.title = title;
        this.pages = pages;
    }
}
```

Now both are valid:

```java
Book book1 = new Book();
Book book2 = new Book("Java Basics", 300);
```

### Key idea

A class can have **multiple constructors** as long as their parameter lists are different.

---

## 2. What Does "Different Parameter List" Mean?

These are different:

```java
Book()
```

```java
Book(String title)
```

```java
Book(String title, int pages)
```

They have different:

* number of parameters
* parameter types
* parameter order

For example:

```java
Book(String title, int pages)
```

and

```java
Book(int pages, String title)
```

are also different parameter lists.

But this is **not allowed**:

```java
Book(String title, int pages)
Book(String name, int numberOfPages)
```

Why?

Because parameter **names don't matter** when determining whether constructors are different.

Both have:

```text
String, int
```

# 3. Constructor Overloading

This ability to have multiple constructors with different parameter lists is called:

**Constructor overloading.**

You've already seen **method overloading** conceptually before.

For example:

```java
void display()
```

and

```java
void display(String name)
```

could coexist because their parameter lists differ.

Constructors work the same way.

```java
class Student {

    Student() {
    }

    Student(String name) {
    }

    Student(String name, int age) {
    }
}
```

This gives you different ways to create a `Student`.

```java
Student student1 = new Student();

Student student2 = new Student("Alice");

Student student3 = new Student("Bob", 21);
```
