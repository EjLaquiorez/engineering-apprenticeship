## 1. Class vs. Object

You already understand that a **class is a blueprint**.

For example:

```java
class Dog {
    String breed;
    String color;
}
```

This defines what a `Dog` **can have**.

But this doesn't create an actual dog.

To create an object:

```java
Dog myDog = new Dog();
```

Let's break this down:

```text
Dog myDog = new Dog();
│    │       │
│    │       └── creates a new Dog object
│    │
│    └── variable that refers to the object
│
└── type
```

The important keyword is:

```java
new
```

`new Dog()` creates a new object based on the `Dog` class.

---

## 2. Think of it like a blueprint

Imagine:

```text
             CLASS
          ┌───────────┐
          │    Dog    │
          │           │
          │ breed     │
          │ color     │
          └───────────┘
               │
              new
               ↓
        ┌─────────────┐
        │   myDog     │
        │             │
        │ breed       │
        │ color       │
        └─────────────┘
             OBJECT
```

The class is the **design**.

The object is the **actual thing created from that design**.
