# Exercise 15A — Find the Encapsulation Problems

Look at this class:

```java
public class Exercise15A {

    static class Student {
        public String name;
        public int age;
        public double grade;

        public void displayStudent() {
            System.out.println(name + " - " + age + " - " + grade);
        }
    }

    public static void main(String[] args) {

        Student student = new Student();

        student.name = "John";
        student.age = -50;
        student.grade = 150;

        student.displayStudent();
    }
}
```

There are several encapsulation problems here.

### Your task

Identify **at least three problems** with this design.

Think about what we learned:

```text
private fields
access modifiers
getters/setters
validation
behavior
```

For each problem, explain **why** it is a problem.

For example, don't just say:

> "`name` should be private."

Instead explain:

> "`name` is public, so outside code can directly change the student's state without going through the Student class."

### Your turn

Find **3 or more problems** in `Exercise15A`.
