## Lesson 28A — First concept

An abstract class is a class declared with the `abstract` keyword. It can define shared state and behavior, but Java does not allow you to instantiate it directly.

Consider:

```
abstract class LibraryItem {
    public void displayType() {
        System.out.println("Library item");
    }
}
```

The method `displayType()` already has an implementation. An abstract class does not have to contain only unfinished methods.

Compare these declarations:

```
LibraryItem item;                 // Valid
// LibraryItem item = new LibraryItem(); // Invalid
```

The first declares a reference variable. The second attempts to create an abstract-class object, which Java prohibits.

## 1. Review your understanding

Given this code:

```
abstract class Animal {
}

class Dog extends Animal {
}
```

- `Animal` is abstract, so you cannot create an object directly with `new Animal()`.
- `Dog` is concrete, so you can create an object with `new Dog()`.
- `Dog` inherits from `Animal`, even though you never create an `Animal` object directly.

Remember, a child class can be instantiated only if it fulfills the requirements for a concrete class. In this example, `Animal` has no abstract methods that `Dog` needs to implement.
