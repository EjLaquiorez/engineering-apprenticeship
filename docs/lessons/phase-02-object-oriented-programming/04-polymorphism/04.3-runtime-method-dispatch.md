## 1. The key concept

Remember this from Lesson 23:

Java
```
Animal animal = new Dog();
```

* `Animal` is the reference type.

* `Dog` is the actual object type.

* The reference type controls which methods are accessible.

Now let's add a method.

Java

```
static class Animal {
    public void makeSound() {
        System.out.println("Animal sound");
    }
}

static class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Woof!");
    }
}
```

Both classes have a `makeSound()` method. The `Dog` class overrides the method inherited from `Animal`.

Now consider:

Java

```
Animal animal = new Dog();
animal.makeSound();
```

Correct! ✅ B. `Woof!`

Now let's understand why this happens. This is the main idea of Lesson 24.

## 1. Why does Java print `Woof!`?

Consider:

Java

```
Animal animal = new Dog();
animal.makeSound();
```

Java sees two important things:

* Reference type: `Animal`

* Actual object type: `Dog`

The `Animal` reference allows us to call `makeSound()` because that method exists in `Animal`.

But when the program runs, Java checks the actual object type to determine which overridden implementation to execute. The actual object is a `Dog`, so Java calls `Dog.makeSound()`.

Reference: `Animal`

Allows the method call

Actual object: `Dog`

Determines the overridden method at runtime

## Output: `Woof!`

This is called runtime method dispatch (also known as dynamic method dispatch).

## 2. Exercise 24A — Runtime Dispatch

Let's test your understanding with a small prediction exercise.

Consider this code:

Java

```
static class Animal {
    public void eat() {
        System.out.println("Animal is eating");
    }
}

static class Dog extends Animal {
    @Override
    public void eat() {
        System.out.println("Dog is eating");
    }
}

static class Cat extends Animal {
    @Override
    public void eat() {
        System.out.println("Cat is eating");
    }
}
```

And the `main()` method:

Java

```
Animal animal1 = new Dog();
Animal animal2 = new Cat();

animal1.eat();
animal2.eat();
```
