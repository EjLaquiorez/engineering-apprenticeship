## 1. The key concept

Remember this from Lesson 23:

Java

```
Animal animal = new Dog();
```

* `Animal` is the reference type.

* `Dog` is the actual object type.

* The reference type controls which methods are accessible.

Now let's add a method.

Java

```
static class Animal {
    public void makeSound() {
        System.out.println("Animal sound");
    }
}

static class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Woof!");
    }
}
```

Both classes have a `makeSound()` method. The `Dog` class overrides the method inherited from `Animal`.

Now consider:

Java

```
Animal animal = new Dog();
animal.makeSound();
```
