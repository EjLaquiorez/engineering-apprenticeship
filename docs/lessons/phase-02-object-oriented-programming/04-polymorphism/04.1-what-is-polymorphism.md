# Lesson 22 — What Is Polymorphism?

Let's start with the word itself.

**Poly** = many
**Morph** = forms

So polymorphism roughly means:

> **One type can take many forms.**

We already have the perfect example from your Topic 3 project:

```text
Employee
├── Manager
└── Developer
```

Both are Employees:

```text
Manager IS-A Employee
Developer IS-A Employee
```

And both have:

```java
work()
```

But they can behave differently:

```text
Manager.work()
→ "Manager is working"

Developer.work()
→ "Developer is working"
```

That gives us the basic idea:

```text
Same method
     ↓
Different child behavior
```

## 🔍 Your first reasoning exercise

Don't write code yet.

Suppose we have:

```java
class Animal {
    public void makeSound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Woof");
    }
}

class Cat extends Animal {
    @Override
    public void makeSound() {
        System.out.println("Meow");
    }
}
```

Now imagine:

```java
Animal animal1 = new Dog();
Animal animal2 = new Cat();
```

### Question 1

What do you think this prints?

```java
animal1.makeSound();
animal2.makeSound();
```

Choose one:

**A**

```text
Animal sound
Animal sound
```

**B**

```text
Woof
Meow
```

**C**

```text
Woof
Woof
```

**D**

```text
Meow
Meow
```

And most importantly: **why?**

Don't worry about being wrong. I want your reasoning first.

✅ **Correct — B.**

```text
Woof
Meow
```

Here's the important part:

```java
Animal animal1 = new Dog();
Animal animal2 = new Cat();
```

Even though both references are declared as `Animal`, the **actual objects** are different:

```text
animal1 → Dog object
animal2 → Cat object
```

So when Java sees:

```java
animal1.makeSound();
```

it uses the `Dog` version:

```text
Woof
```

And:

```java
animal2.makeSound();
```

uses the `Cat` version:

```text
Meow
```

### The key idea

```text
Animal reference
      ↓
 ┌────┴────┐
 ↓         ↓
Dog       Cat
 ↓         ↓
Woof      Meow
```

That's **polymorphism**:

> **One parent type (`Animal`) can refer to different child objects, and those objects can behave differently.**

---

### One important distinction

Don't think:

> "`Animal` changes into `Dog`."

Instead think:

> **The reference is an `Animal`, but the object it refers to is a `Dog`.**
