# Lesson 16 — What Is Inheritance?

You've already learned that a class is a blueprint for objects.

Now imagine we have:

```text
Animal
```

Animals might have common characteristics:

```text
name
age
eat()
sleep()
```

Then we have:

```text
Dog
Cat
```

Both are animals.

A dog might additionally have:

```text
bark()
```

A cat might additionally have:

```text
meow()
```

Instead of duplicating the common `name`, `age`, `eat()`, and `sleep()` in every class, Java allows a child class to **inherit** them from a parent class.

The syntax is:

```java
class Dog extends Animal {
    
}
```

Read this as:

> **Dog extends Animal.**

Or conceptually:

> **Dog is an Animal.**

That second statement is extremely important.

---

## The "is-a" relationship

Inheritance generally represents an **is-a** relationship.

```text
Dog → Animal
```

Ask:

> Is a Dog an Animal?

Yes.

Therefore inheritance can make sense.

But:

```text
Car → Engine
```

Ask:

> Is a Car an Engine?

No.

A car **has an** engine.

That's a different relationship, which we'll study more deeply in Lesson 21.
