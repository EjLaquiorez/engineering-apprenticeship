## Lesson 16 — What Is Inheritance?

**Goal:** Understand how one class can inherit common data and behavior from another class.

### 1. The problem inheritance solves

Imagine we have these classes:

```text
Dog
- name
- age
- eat()
- sleep()
- bark()

Cat
- name
- age
- eat()
- sleep()
- meow()
```

Notice something?

Both `Dog` and `Cat` have:

* `name`
* `age`
* `eat()`
* `sleep()`

We're repeating the same code.

Inheritance lets us move the common parts into a parent class:

```text
             Animal
            /      \
          Dog      Cat
```

`Animal` can contain the common things:

```java
class Animal {
    String name;
    int age;

    void eat() {
        System.out.println("Eating...");
    }

    void sleep() {
        System.out.println("Sleeping...");
    }
}
```

Then:

```java
class Dog extends Animal {
}
```

The important keyword is:

```java
extends
```

It means:

> `Dog` inherits from `Animal`.

---

## 2. Parent and child classes

There are several names for the same relationship:

| Concept      | Other names              |
| ------------ | ------------------------ |
| Parent class | superclass / base class  |
| Child class  | subclass / derived class |

So:

```java
class Dog extends Animal
```

means:

```text
Animal = parent/superclass
Dog    = child/subclass
```

A `Dog` object can use the members it inherits from `Animal`.

For example:

```java
Dog dog = new Dog();

dog.name = "Buddy";
dog.age = 3;
dog.eat();
dog.sleep();
```

Even though `name`, `age`, `eat()`, and `sleep()` were declared in `Animal`, the `Dog` inherits them.

---

## 3. The most important idea: "is-a"

Inheritance should represent an **is-a relationship**.

Ask:

> "Is a Dog an Animal?"

Yes.

```text
Dog is an Animal
```

Therefore:

```java
class Dog extends Animal
```

makes sense.

Another example:

```text
Car is a Vehicle
```

So:

```java
class Car extends Vehicle
```

could make sense.

But:

```text
Library is a Book
```

does **not** make sense.

A library **has books**.

That's a different relationship:

```text
Library HAS-A Book
```

We'll study this distinction more deeply in Lesson 21.

| 2 | Car → Vehicle    | ✅ Yes       | A Car **is a** Vehicle                    |

| 4 | Cat → Animal     | ✅ Yes       | A Cat **is an** Animal                    |
| 5 | Student → School | ✅ No        | A Student **belongs to/attends** a School |

### The key rule

Before using `extends`, ask:

> **"Is a [child] a [parent]?"**

If the answer is naturally **yes**, inheritance may make sense.

```text
Dog is an Animal     → inheritance can make sense
Car is a Vehicle     → inheritance can make sense

Library is a Book    → ❌
Student is a School  → ❌
```

For the last two, we're dealing with relationships other than inheritance. We'll formally compare **is-a vs has-a** in Lesson 21.
