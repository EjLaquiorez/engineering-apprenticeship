> **A child class should reuse what belongs to the parent while adding what makes that child different.**

---

# 1. What does a child class get?

Remember our hierarchy:

```text
             Animal
            /      \
          Dog      Cat
```

Suppose `Animal` contains:

```java
static class Animal {
    String name;
    int age;

    void eat() {
        System.out.println("Eating...");
    }

    void sleep() {
        System.out.println("Sleeping...");
    }
}
```

Then:

```java
static class Dog extends Animal {
}
```

`Dog` automatically gets access to the inherited members.

Conceptually:

```text
Dog
├── name       ← inherited
├── age        ← inherited
├── eat()      ← inherited
└── sleep()    ← inherited
```

You don't rewrite those members inside `Dog`.

That's one of the main benefits of inheritance.

---

# 2. But children can have their own members

A Dog can have something that an Animal doesn't specifically have.

For example:

```text
Dog
├── inherited: name
├── inherited: age
├── inherited: eat()
├── inherited: sleep()
└── own: breed
```

And a Cat might have:

```text
Cat
├── inherited: name
├── inherited: age
├── inherited: eat()
├── inherited: sleep()
└── own: furColor
```

So inheritance doesn't mean:

> "The child can only use what the parent has."

It means:

> **"The child starts with what the parent provides and can add its own specialized members."**

# Exercise 18A — Create Two Child Classes

Let's start simple.

Create `Exercise18A.java`.

Create this parent:

```text
Animal
```

with:

```text
name
age
eat()
sleep()
```

Then create **two child classes**:

```text
Dog extends Animal
Cat extends Animal
```

For this exercise, **don't add any new fields or methods to Dog or Cat yet**.

In `main()`:

1. Create a `Dog` object.
2. Create a `Cat` object.
3. Use the inherited `eat()` method on both.
4. Use the inherited `sleep()` method on both.

### Important

Don't copy `eat()` or `sleep()` into `Dog` or `Cat`.

The purpose is to demonstrate:

```text
Animal
   ↓
extends
   ↓
Dog / Cat
   ↓
reuse inherited behavior
```
