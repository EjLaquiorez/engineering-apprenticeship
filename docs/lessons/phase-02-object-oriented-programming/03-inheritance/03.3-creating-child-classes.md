# 1. What does a child class get?

Remember our hierarchy:

```text
             Animal
            /      \
          Dog      Cat
```

Suppose `Animal` contains:

```java
static class Animal {
    String name;
    int age;

    void eat() {
        System.out.println("Eating...");
    }

    void sleep() {
        System.out.println("Sleeping...");
    }
}
```

Then:

```java
static class Dog extends Animal {
}
```

`Dog` automatically gets access to the inherited members.

Conceptually:

```text
Dog
├── name       ← inherited
├── age        ← inherited
├── eat()      ← inherited
└── sleep()    ← inherited
```

You don't rewrite those members inside `Dog`.

That's one of the main benefits of inheritance.

---

# 2. But children can have their own members

A Dog can have something that an Animal doesn't specifically have.

For example:

```text
Dog
├── inherited: name
├── inherited: age
├── inherited: eat()
├── inherited: sleep()
└── own: breed
```

And a Cat might have:

```text
Cat
├── inherited: name
├── inherited: age
├── inherited: eat()
├── inherited: sleep()
└── own: furColor
```

So inheritance doesn't mean:

> "The child can only use what the parent has."

It means:

> **"The child starts with what the parent provides and can add its own specialized members."**

## Issue 2 — Your `main()` has a Java syntax error

You wrote:

```java
Dog dog1 = new Dog(browny, 3, labrador);
Cat cat1 = new Cat(Mawmaw, 2);
```

Java thinks `browny`, `labrador`, and `Mawmaw` are **variable names**.

If you mean text, they need to be **String literals**:

```java
"browny"
"labrador"
"Mawmaw"
```

However, once you remove the child-specific `breed` from 18A, your `Dog` constructor should only receive the parameters required by `Animal`.
