# 1. What does a child class get?

Remember our hierarchy:

```text
             Animal
            /      \
          Dog      Cat
```

Suppose `Animal` contains:

```java
static class Animal {
    String name;
    int age;

    void eat() {
        System.out.println("Eating...");
    }

    void sleep() {
        System.out.println("Sleeping...");
    }
}
```

Then:

```java
static class Dog extends Animal {
}
```

`Dog` automatically gets access to the inherited members.

Conceptually:

```text
Dog
├── name       ← inherited
├── age        ← inherited
├── eat()      ← inherited
└── sleep()    ← inherited
```

You don't rewrite those members inside `Dog`.

That's one of the main benefits of inheritance.

---

# 2. But children can have their own members

A Dog can have something that an Animal doesn't specifically have.

For example:

```text
Dog
├── inherited: name
├── inherited: age
├── inherited: eat()
├── inherited: sleep()
└── own: breed
```

And a Cat might have:

```text
Cat
├── inherited: name
├── inherited: age
├── inherited: eat()
├── inherited: sleep()
└── own: furColor
```

So inheritance doesn't mean:

> "The child can only use what the parent has."

It means:

> **"The child starts with what the parent provides and can add its own specialized members."**

### What you demonstrated correctly

Your hierarchy is now:

```text
                 Animal
              /    |    \
            Dog   Cat   Bird
             |     |      |
           breed furColor wingSpan
```

The parent owns the common state:

```java
private final String name;
private final int age;
```

while each child owns its specialized state:

```java
Dog   → breed
Cat   → furColor
Bird  → wingSpan
```

That's exactly the concept we're practicing.

### Your constructors

This is also correct:

```java

    super(name, age);
    this.breed = breed;

```

Notice the responsibilities:

```text
super(name, age)
        ↓
Animal initializes name + age

this.breed = breed
        ↓
Dog initializes its own breed
```

That's an important inheritance pattern.
