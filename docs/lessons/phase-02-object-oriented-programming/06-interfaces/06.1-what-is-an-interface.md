## 1. Code review

Your code:

```
public class Exercise31A {
    interface Summarizable {
        public void summarize();
    }

    public static void main(String[] args) {
    }
}
```

Interface declaration

`interface Summarizable` correctly declares an interface nested inside your class.

Method signature

`public void summarize();` has the correct name, return type, and parameter list.

No method body

You correctly ended the declaration with a semicolon instead of adding curly braces.

### One thing to understand

In Java, interface methods declared this way are implicitly `public` and `abstract`. That means you could also write:

```
void summarize();
```

Both declarations are valid. Keeping `public` is fine while you're learning.
