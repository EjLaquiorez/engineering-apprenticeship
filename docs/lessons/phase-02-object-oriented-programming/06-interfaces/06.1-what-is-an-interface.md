No method body

### One thing to understand

In Java, interface methods declared this way are implicitly `public` and `abstract`. That means you could also write:

```
void summarize();
```

Both declarations are valid. Keeping `public` is fine while you're learning.

The correct answer is B. Provide a `public` implementation of `summarize()`.

Remember these two keywords:

| Keyword      | Purpose                                                                |
| ------------ | ---------------------------------------------------------------------- |
| `extends`    | Inherits from a class, or extends an interface from another interface. |
| `implements` | A class agrees to fulfill an interface's contract.                     |

For example, the relationship we're learning is:

`Summarizable`

Interface: requires `summarize()`

implements

`Book`

Class: provides `summarize()`

One important detail: because `summarize()` is implicitly `public` in the interface, the implementing method must also be `public`.
