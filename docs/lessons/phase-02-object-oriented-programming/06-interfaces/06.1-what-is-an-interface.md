## 2. Important concept: What does the interface enforce?

The interface declares what a class must provide, not how that behavior must work.

Your `Book` class prints `"This is a book."`, while another class could implement `summarize()` to print a report summary. Both can fulfill the same contract differently.

## 2. Let's strengthen your understanding

Your code uses these declarations:

```
Book book = new Book();
Report report = new Report();
```

Java also allows you to declare variables using the interface type:

```
Summarizable book = new Book();
Summarizable report = new Report();
```

This works because both objects implement `Summarizable`.

The interface reference lets you work with different kinds of objects through the same contract. You can call `summarize()` without needing to know whether the actual object is a `Book` or a `Report`.
