## 1. A new way to refer to objects

In Exercise 31C, you wrote:

```
Book book = new Book();
Report report = new Report();
```

These variables use their concrete class types.

But because both classes implement `Summarizable`, Java also permits:

```
Summarizable book = new Book();
Summarizable report = new Report();
```

Let's understand why this matters.

- `new Book()` creates a `Book` object.
- `Summarizable book` declares a reference whose type is the interface.
- `book.summarize()` calls the implementation provided by the actual object.

The interface reference exposes the behavior promised by the contract without requiring the calling code to depend on the concrete class.
