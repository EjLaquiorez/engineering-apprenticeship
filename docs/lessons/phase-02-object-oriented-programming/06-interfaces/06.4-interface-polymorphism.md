## 2. Core concept: One interface, many object types

Remember your `Exercise33C` classes:

- `Book` implements `Describable`.
- `Magazine` implements `Describable`.
- `LibraryReport` implements `Describable`.

Because all three implement `Describable`, Java lets you refer to each object through that interface.

For example, you already know this pattern:

```
Describable item = new Book();
item.describe();
```

The important next step is understanding that you can place different `Describable` objects into the same array and process them with one loop.
