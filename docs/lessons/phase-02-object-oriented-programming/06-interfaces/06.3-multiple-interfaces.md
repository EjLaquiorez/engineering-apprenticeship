## 2. Core concept: A class can implement multiple interfaces

Imagine your library management system has a `Book` class.

A book might have two separate capabilities:

- Describable: it can describe its information.
- Printable: it can print its information.

These are different responsibilities, but one `Book` object can support both.

## Book

One class, two capabilities

Describable

`describe()`

Printable

`print()`

In Java, a class uses `implements` followed by a comma-separated list of interfaces:

```
class Book implements Describable, Printable {
    // Must implement both interfaces' required methods.
}
```

Notice that Java allows a class to extend one class but implement multiple interfaces.

If both interfaces declare separate abstract methods, a concrete `Book` class must implement both methods. It doesn't need to inherit from two parent classes.
