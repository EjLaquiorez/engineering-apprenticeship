## 2. Exercise 35A — Design an Interface

Let's reuse your library-system examples.

Here are the required capabilities:

| Class           | Describe | Print | Borrow |
| --------------- | -------- | ----- | ------ |
| `Book`          | Yes      | Yes   | Yes    |
| `Magazine`      | Yes      | No    | Yes    |
| `LibraryReport` | Yes      | Yes   | No     |

Consider two possible designs.

Design A — Separate interfaces

- `Describable` declares `describe()`.
- `Printable` declares `print()`.
- `Borrowable` declares `borrow()`.

Each class implements only the interfaces it needs.

Design B — One combined interface

- `LibraryItemActions` declares all three methods.
- Every class implements `LibraryItemActions`, even if some operations don't apply to it.
