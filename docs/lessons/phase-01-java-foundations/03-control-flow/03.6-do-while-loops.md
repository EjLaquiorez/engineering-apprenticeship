## 1. The key difference

A `while` loop checks the condition **before** executing the body:

```java
while (condition) {
    // code
}
```

A `do-while` loop executes the body **first**, then checks the condition:

```java
do {
    // code
} while (condition);
```

This means a `do-while` loop **always executes at least once**.

---

## 2. Simple example

```java
int count = 1;

do {
    System.out.println(count);
    count++;
} while (count <= 5);
```

Output:

```text
1
2
3
4
5
```

The process is:

```text
execute body
     ↓
check condition
     ↓
 true ─────→ execute body again
     ↓
 false
     ↓
    STOP
```

---

# 3. The important difference

Compare these two.

### `while`

```java
int number = 10;

while (number < 5) {
    System.out.println(number);
}
```

Output:

```text
nothing
```

The condition is already false.

---

### `do-while`

```java
int number = 10;

do {
    System.out.println(number);
} while (number < 5);
```

Output:

```text
10
```

Why?

Because Java executes:

```java
System.out.println(number);
```

**before** checking:

```java
number < 5
```

Then:

```text
10 < 5 → false
```

and the loop stops.

This is the defining characteristic of `do-while`.

---

# 4. Real-world use

A `do-while` is useful when something needs to happen **at least once**.

For example, a menu:

```java
int choice;

do {
    System.out.println("1. View account");
    System.out.println("2. Exit");

    choice = scanner.nextInt();

} while (choice != 2);
```

The menu needs to be displayed at least once before we can ask whether the user wants to exit.

Another common example is input validation:

```text
Ask user for age
      ↓
Is age valid?
   ↓       ↓
 yes       no
  ↓         ↓
 STOP    ask again
```

The user must be asked at least once.

---

# 5. The semicolon matters

Notice:

```java
} while (condition);
```

There is a **semicolon** after the condition.

Correct:

```java
do {
    System.out.println("Hello");
} while (condition);
```

Incorrect:

```java
do {
    System.out.println("Hello");
} while (condition)
```

For a `do-while`, that semicolon is part of the syntax.

---

# 6. `while` vs `do-while`

Think about them this way:

### `while`

> **Should I execute this?**

```text
check → execute → check → execute
```

### `do-while`

> **Execute this, then decide whether I should continue.**

```text
execute → check → execute → check
```

That difference is small syntactically but important conceptually.
