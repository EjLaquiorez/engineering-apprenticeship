## 1. Why `for` loops exist

You've already used `while`:

```java
int count = 1;

while (count <= 5) {
    System.out.println(count);
    count++;
}
```

Notice that the loop has three important pieces:

```text
initialization
condition
update
```

A `for` loop puts those three pieces together:

```java
for (initialization; condition; update) {
    // repeated code
}
```

The same counting loop becomes:

```java
for (int count = 1; count <= 5; count++) {
    System.out.println(count);
}
```

Output:

```text
1
2
3
4
5
```

---

# 2. Understand the three parts

Look at:

```java
for (int count = 1; count <= 5; count++) {
    System.out.println(count);
}
```

### Initialization

```java
int count = 1
```

Runs **once**, before the loop starts.

### Condition

```java
count <= 5
```

Checked before every iteration.

### Update

```java
count++
```

Runs after each iteration.

So the execution is:

```text
initialize
    ↓
check condition
    ↓
true → execute body
    ↓
update
    ↓
check condition again
    ↓
...
    ↓
false
    ↓
STOP
```

---

# 3. `for` vs `while`

These two programs are equivalent:

### `while`

```java
int count = 1;

while (count <= 5) {
    System.out.println(count);
    count++;
}
```

### `for`

```java
for (int count = 1; count <= 5; count++) {
    System.out.println(count);
}
```

The main difference is **organization**.

A `for` loop is especially useful when you know the general structure of the repetition:

> Start here → continue while this is true → change the counter this way.

A `while` loop is often more natural when the stopping condition depends on something that may happen unpredictably, such as user input.

---

# 4. Counting downward

You can use a `for` loop for countdowns too:

```java
for (int count = 5; count >= 1; count--) {
    System.out.println(count);
}
```

Output:

```text
5
4
3
2
1
```

---

# 5. Different update expressions

The update doesn't have to be `count++`.

### Increase by 2

```java
for (int count = 2; count <= 10; count += 2) {
    System.out.println(count);
}
```

Output:

```text
2
4
6
8
10
```

### Increase by 5

```java
for (int count = 0; count <= 20; count += 5) {
    System.out.println(count);
}
```

Output:

```text
0
5
10
15
20
```

The update determines how the loop progresses.

---

# 6. Scope of the loop variable

Consider:

```java
for (int count = 1; count <= 5; count++) {
    System.out.println(count);
}
```

The variable `count` exists only inside the `for` loop.

This will **not** work:

```java
for (int count = 1; count <= 5; count++) {
    System.out.println(count);
}

System.out.println(count); // ERROR
```

Why?

Because `count` was declared inside the `for` loop.

This connects directly to **Lesson 02 — Variable Scope**.

# 7. Nested `for` loops

A loop can contain another loop.

Example:

```java
for (int row = 1; row <= 3; row++) {

    for (int column = 1; column <= 3; column++) {
        System.out.println("Row " + row + ", Column " + column);
    }

}
```

The outer loop controls the rows.

The inner loop runs completely for each outer iteration.

Conceptually:

```text
Row 1 → Column 1
       → Column 2
       → Column 3

Row 2 → Column 1
       → Column 2
       → Column 3

Row 3 → Column 1
       → Column 2
       → Column 3
```

Nested loops will become particularly important when we reach **arrays**.

---

# 8. Common mistake: off-by-one

Consider:

```java
for (int count = 1; count < 5; count++) {
    System.out.println(count);
}
```

What prints?

```text
1
2
3
4
```

Not:

```text
1
2
3
4
5
```

Because:

```java
count < 5
```

means **strictly less than 5**.

Compare:

```java
count < 5
```

with:

```java
count <= 5
```

This distinction is extremely important.

---

# 9. Another common mistake

Look at:

```java
for (int count = 1; count <= 5; count--) {
    System.out.println(count);
}
```

The condition says:

```text
count <= 5
```

and the update makes:

```text
1 → 0 → -1 → -2 → ...
```

Those values continue to satisfy:

```text
count <= 5
```

So the loop never reaches its stopping condition.

This is the same type of problem you encountered with the broken `while` and `do-while` loops.
