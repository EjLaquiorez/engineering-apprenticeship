# Lesson 09 — `if`, `else if`, and `else`

In Lesson 08, you learned how Java produces `true` and `false` from comparisons.

Now we're going to use those boolean expressions to make the program **choose what code to execute**.

This is the beginning of actual program decision-making.

---

## Lesson Objective

By the end of this lesson, you should understand:

* How `if` works
* How conditions control execution
* How `{ }` define a block
* How `else` works
* How `else if` works
* How Java chooses between multiple conditions
* What happens when no condition is true
* Common conditional mistakes

Our mental model:

```text
boolean expression
       ↓
   true / false
       ↓
    if / else
       ↓
execute different code
```

---

# 1. The `if` Statement

The basic structure is:

```java
if (condition) {
    // code
}
```

Example:

```java
int age = 20;

if (age >= 18) {
    System.out.println("Adult");
}
```

Java evaluates:

```text
20 >= 18
```

which produces:

```text
true
```

Therefore Java executes:

```java
System.out.println("Adult");
```

Output:

```text
Adult
```

---

# 2. What If the Condition Is False?

Consider:

```java
int age = 15;

if (age >= 18) {
    System.out.println("Adult");
}
```

Java evaluates:

```text
15 >= 18
```

Result:

```text
false
```

Therefore Java **skips the block**.

Nothing is printed.

This is the fundamental behavior of `if`:

```text
condition true
     ↓
execute block

condition false
     ↓
skip block
```

---

# 3. The Condition Must Produce a Boolean

This is important.

Valid:

```java
if (age >= 18) {
    System.out.println("Adult");
}
```

because:

```text
age >= 18
```

produces a boolean.

You can also use a boolean variable:

```java
boolean isAdult = true;

if (isAdult) {
    System.out.println("Adult");
}
```

But this is invalid:

```java
if (age) {
    System.out.println("Adult");
}
```

if `age` is an `int`.

Java does **not** automatically treat:

```text
1 → true
0 → false
```

like some other languages do.

Java requires an actual boolean condition.

---

# 4. The `{ }` Block

Consider:

```java
if (age >= 18) {
    System.out.println("Adult");
    System.out.println("Can vote");
}
```

The braces define the code belonging to the `if`.

Both statements execute when the condition is true.

Think of it as:

```text
if condition is true:
    do EVERYTHING inside { }
```

---

# 5. `if` and Variable Scope

This connects directly to Lesson 02.

```java
int age = 20;

if (age >= 18) {
    String message = "Adult";
    System.out.println(message);
}
```

`message` exists only inside the `if` block.

This won't work:

```java
int age = 20;

if (age >= 18) {
    String message = "Adult";
}

System.out.println(message);
```

because `message` was declared inside the block.

Remember:

```text
outer scope
    ↓
    if block
        ↓
    variables declared here
    exist here
```

---

# 6. Adding `else`

Sometimes we don't want to simply skip code.

We want:

> Do one thing if true, otherwise do another thing.

That's what `else` provides.

```java
int age = 15;

if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}
```

Java evaluates:

```text
15 >= 18
```

→ `false`

So Java skips the first block and executes the `else` block.

Output:

```text
Minor
```

---

# 7. `if` + `else`

The structure is:

```java
if (condition) {
    // runs when true
} else {
    // runs when false
}
```

Exactly **one** of these blocks will execute.

For example:

```java
int age = 25;

if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}
```

Output:

```text
Adult
```

There is no situation where both blocks execute.

---

# 8. `else if`

What if we have more than two possibilities?

For example:

```text
90+ → Excellent
75–89 → Good
60–74 → Passing
below 60 → Failing
```

We can use `else if`.

```java
int score = 82;

if (score >= 90) {
    System.out.println("Excellent");
} else if (score >= 75) {
    System.out.println("Good");
} else if (score >= 60) {
    System.out.println("Passing");
} else {
    System.out.println("Failing");
}
```

Java checks the conditions **from top to bottom**.

---

# 9. How `else if` Is Evaluated

For:

```java
int score = 82;
```

Java starts here:

```text
score >= 90
```

```text
82 >= 90 → false
```

Then:

```text
score >= 75
```

```text
82 >= 75 → true
```

So Java executes:

```java
System.out.println("Good");
```

Then it **stops checking the rest of the chain**.

It doesn't continue to:

```text
score >= 60
```

because a matching condition has already been found.

---

# 10. First True Condition Wins

This is one of the most important rules.

Consider:

```java
int score = 95;

if (score >= 60) {
    System.out.println("Passing");
} else if (score >= 90) {
    System.out.println("Excellent");
}
```

What happens?

The first condition is:

```text
95 >= 60
```

→ `true`

So Java prints:

```text
Passing
```

It **never reaches** the `else if`.

Even though `95 >= 90` is also true.

Therefore:

> In an `if` / `else if` / `else` chain, the **first true condition wins**.

This makes the order of conditions extremely important.

---

# 11. Correct Ordering

Usually, when dealing with ranges, place the more specific/higher threshold first.

Better:

```java
if (score >= 90) {
    System.out.println("Excellent");
} else if (score >= 60) {
    System.out.println("Passing");
} else {
    System.out.println("Failing");
}
```

Now:

```text
95 → Excellent
75 → Passing
40 → Failing
```

---

# 12. `else` Is the Default

Consider:

```java
if (score >= 90) {
    System.out.println("Excellent");
} else if (score >= 60) {
    System.out.println("Passing");
} else {
    System.out.println("Failing");
}
```

The `else` doesn't have a condition.

It means:

> If none of the previous conditions were true, execute this.

So:

```text
90+ → first block
60–89 → second block
below 60 → else
```

---

# 13. You Don't Always Need `else`

You can have:

```java
if (temperature > 30) {
    System.out.println("Hot");
}
```

There is nothing wrong with having no `else`.

It means:

> Only do something when this condition is true.

---

# 14. Multiple Independent `if` Statements

Be careful about the difference between:

```java
if (condition1) {
    ...
}

if (condition2) {
    ...
}
```

and:

```java
if (condition1) {
    ...
} else if (condition2) {
    ...
}
```

The first has **independent decisions**.

Both can execute.

Example:

```java
int age = 20;

if (age >= 18) {
    System.out.println("Adult");
}

if (age >= 21) {
    System.out.println("21 or older");
}
```

Output:

```text
Adult
```

The second condition is false.

But if:

```java
int age = 25;
```

both conditions are true, so both blocks execute:

```text
Adult
21 or older
```

---

# 15. `if` / `else if` Is Different

Now:

```java
int age = 25;

if (age >= 18) {
    System.out.println("Adult");
} else if (age >= 21) {
    System.out.println("21 or older");
}
```

Only:

```text
Adult
```

prints.

Why?

Because the first condition:

```text
25 >= 18
```

is already true.

The `else if` is skipped.

---

# 16. Nested `if`

You can put an `if` inside another `if`.

Example:

```java
int age = 25;
boolean hasLicense = true;

if (age >= 18) {

    if (hasLicense) {
        System.out.println("Can drive");
    }
}
```

The inner `if` is only evaluated if the outer `if` is true.

Conceptually:

```text
age >= 18?
    ↓
   yes
    ↓
hasLicense?
    ↓
   yes
    ↓
Can drive
```

We'll eventually combine conditions using `&&` and `||` in Lesson 10.

---

# 17. Common Mistake — Assignment Instead of Comparison

Remember Lesson 08:

```text
=   → assignment
==  → comparison
```

When writing conditions, you usually want:

```java
if (age == 18) {
    ...
}
```

not:

```java
if (age = 18) {
    ...
}
```

The second one is not a valid boolean condition because you're trying to assign an integer.

---

# 18. Common Mistake — Semicolon After `if`

Be careful with:

```java
if (age >= 18); {
    System.out.println("Adult");
}
```

That semicolon:

```text
;
```

ends the `if` statement.

The block is no longer controlled by the `if` the way you intended.

Don't write:

```java
if (condition);
```

Write:

```java
if (condition) {
    ...
}
```

---

# 19. Common Mistake — Incorrect Range Logic

Suppose you want:

```text
score between 60 and 100
```

You might initially think:

```java
if (60 <= score <= 100)
```

But Java does **not** support chained comparisons like that.

We'll learn how to correctly express this when we reach **Lesson 10 — Logical Operators**.

For now, remember that comparisons produce individual boolean values.
