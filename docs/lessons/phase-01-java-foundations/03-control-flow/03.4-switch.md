# Phase 01 — Java Foundations

## Lesson 11 — `switch`

### Objective

Learn how to use `switch` when you need to choose between multiple discrete values.

---

## 1. Why `switch` exists

Suppose we have:

```java
int day = 3;
```

We could write:

```java
if (day == 1) {
    System.out.println("Monday");
} else if (day == 2) {
    System.out.println("Tuesday");
} else if (day == 3) {
    System.out.println("Wednesday");
} else if (day == 4) {
    System.out.println("Thursday");
}
```

This works, but when we're comparing **one value against many specific possibilities**, `switch` can make the code clearer.

```java
switch (day) {
    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    case 3:
        System.out.println("Wednesday");
        break;

    case 4:
        System.out.println("Thursday");
        break;
}
```

---

# 2. How `switch` works

The basic structure is:

```java
switch (value) {
    case value1:
        // code
        break;

    case value2:
        // code
        break;

    default:
        // code if nothing matches
}
```

Java takes the value inside:

```java
switch (day)
```

and looks for a matching `case`.

If:

```java
day = 3;
```

Java finds:

```java
case 3:
```

and executes its code.

---

# 3. Why `break` matters

Consider:

```java
int day = 2;

switch (day) {
    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    case 3:
        System.out.println("Wednesday");
        break;
}
```

Output:

```text
Tuesday
```

The `break` tells Java:

> We found the matching case. Leave the switch.

Without `break`, Java can continue executing the following cases. This is called **fall-through**.

For example:

```java
int number = 1;

switch (number) {
    case 1:
        System.out.println("One");

    case 2:
        System.out.println("Two");

    case 3:
        System.out.println("Three");
}
```

Output:

```text
One
Two
Three
```

That's usually not what we want.

---

# 4. `default`

What happens if no case matches?

Use `default`:

```java
int day = 10;

switch (day) {
    case 1:
        System.out.println("Monday");
        break;

    case 2:
        System.out.println("Tuesday");
        break;

    case 3:
        System.out.println("Wednesday");
        break;

    default:
        System.out.println("Invalid day");
}
```

Since `10` doesn't match any case:

```text
Invalid day
```

is printed.

Think of `default` as the `switch` equivalent of the "nothing matched" path.

---

# 5. `switch` with `char`

`switch` isn't limited to integers.

For example:

```java
char grade = 'A';

switch (grade) {
    case 'A':
        System.out.println("Excellent");
        break;

    case 'B':
        System.out.println("Good");
        break;

    case 'C':
        System.out.println("Average");
        break;

    default:
        System.out.println("Invalid grade");
}
```

Output:

```text
Excellent
```

---

# 6. `switch` with `String`

You can also switch on a `String`:

```java
String role = "admin";

switch (role) {
    case "admin":
        System.out.println("Full access");
        break;

    case "manager":
        System.out.println("Management access");
        break;

    case "user":
        System.out.println("Standard access");
        break;

    default:
        System.out.println("Unknown role");
}
```

Output:

```text
Full access
```

This is useful for things like commands, menu choices, roles, and categories.

---

# 7. `switch` vs `if`

This distinction is important.

### `switch`

Good when you're asking:

> Is this value exactly one of these known values?

```java
switch (day) {
    case 1:
    case 2:
    case 3:
}
```

### `if`

Better when you're asking about **ranges or complex conditions**:

```java
if (score >= 90) {
    ...
} else if (score >= 75) {
    ...
}
```

You generally wouldn't use `switch` for:

```java
score >= 90
```
