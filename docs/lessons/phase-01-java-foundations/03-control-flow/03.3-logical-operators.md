# Lesson 10 — Logical Operators

You already know how to create **one boolean condition**:

```java
age >= 18
```

But real programs often need to ask questions like:

> Is the user an adult **AND** has a valid license?

or:

> Is the user an admin **OR** a manager?

Logical operators let us **combine boolean expressions**.

---

## 1. `&&` — AND

`&&` means **both conditions must be true**.

```java
int age = 25;
boolean hasLicense = true;

if (age >= 18 && hasLicense) {
    System.out.println("Can drive");
}
```

Break it down:

```text
age >= 18      → true
hasLicense     → true
                    ↓
true && true   → true
```

Both must be true.

### Truth table

| A     | B     | A && B   |
| ----- | ----- | -------- |
| false | false | false    |
| false | true  | false    |
| true  | false | false    |
| true  | true  | **true** |

Think:

> **AND = everything must be true.**

---

# 2. `||` — OR

`||` means **at least one condition must be true**.

```java
boolean isAdmin = false;
boolean isManager = true;

if (isAdmin || isManager) {
    System.out.println("Has management access");
}
```

```text
isAdmin       → false
isManager     → true
                  ↓
false || true → true
```

### Truth table

| A     | B     | A || B   |
| ----- | ----- | -------- |
| false | false | false    |
| false | true  | **true** |
| true  | false | **true** |
| true  | true  | **true** |

Think:

> **OR = at least one must be true.**

---

# 3. `!` — NOT

`!` reverses a boolean value.

```java
boolean loggedIn = false;

if (!loggedIn) {
    System.out.println("Please log in");
}
```

Because:

```text
loggedIn  → false
!loggedIn → true
```

Another example:

```java
boolean active = true;

System.out.println(!active);
```

Output:

```text
false
```

Think:

> **NOT = reverse the boolean.**

---

# 4. Combining Operators

You can combine multiple conditions:

```java
int age = 25;
boolean hasLicense = true;
boolean suspended = false;

if (age >= 18 && hasLicense && !suspended) {
    System.out.println("Allowed to drive");
}
```

Evaluate it:

```text
age >= 18    → true
hasLicense   → true
suspended    → false
!suspended   → true

true && true && true
        ↓
       true
```

Therefore:

```text
Allowed to drive
```

---

# 5. `&&` vs `||`

This distinction is extremely important.

### AND

```java
if (age >= 18 && age <= 60)
```

Means:

> age must be **18 or older AND 60 or younger**.

So:

```text
18 → true
30 → true
60 → true
17 → false
61 → false
```

### OR

```java
if (age < 18 || age > 60)
```

Means:

> age is **under 18 OR over 60**.

So:

```text
17 → true
30 → false
61 → true
```

---

# 6. Parentheses

Parentheses help make complex conditions clear.

Consider:

```java
if (isAdmin || isManager && isActive)
```

Don't rely on your intuition when conditions become complicated.

Instead, use parentheses to make the intended logic explicit:

```java
if (isAdmin || (isManager && isActive))
```

This means:

> The user is an admin, **OR** the user is both a manager and active.

You can also write:

```java
if ((isAdmin || isManager) && isActive)
```

This means something different:

> The user is an admin **or** manager, **AND** must be active.

**Parentheses can change the meaning of the condition.**

---

# 7. Short-Circuit Evaluation

Java doesn't always evaluate every condition.

For `&&`:

```java
false && something
```

Once Java sees the first condition is `false`, the entire expression **must** be false.

So Java can stop.

For `||`:

```java
true || something
```

Once Java sees the first condition is `true`, the entire expression **must** be true.

So Java can stop.

This is called **short-circuit evaluation**.

You don't need to memorize the implementation details yet. Just remember:

> `&&` can stop after `false`.
> `||` can stop after `true`.

---

# 8. Common Mistake — Confusing `&&` and `||`

Suppose you want:

> Allow users who are either an admin or manager.

Correct:

```java
if (isAdmin || isManager)
```

Incorrect:

```java
if (isAdmin && isManager)
```

The incorrect version requires the person to be **both** admin and manager.

---

# 9. Common Mistake — Impossible Conditions

Look at this:

```java
if (age >= 18 && age < 18) {
    System.out.println("Hello");
}
```

Can `age` simultaneously be:

```text
>= 18
```

and:

```text
< 18
```

No.

Therefore this condition can never be true.

This is an example of a **logic error**.

Java can compile perfectly valid code that contains incorrect logic.
