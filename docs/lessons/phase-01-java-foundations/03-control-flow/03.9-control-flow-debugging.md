# Lesson 16 — Control-Flow Debugging

This is the **final lesson in Topic 3 — Control Flow**.

The goal today is not to learn a new control-flow statement. Instead, you'll learn to **debug loops and conditions systematically**.

---

## 1. The Four Common Problems

### A. Infinite loops

A loop never reaches its stopping condition.

```java
int number = 1;

while (number <= 5) {
    System.out.println(number);
}
```

What is missing?

```java
number++;
```

Without changing `number`, this remains:

```text
1 <= 5 → true
1 <= 5 → true
1 <= 5 → true
...
```

---

### B. Off-by-one errors

You intend:

```text
1 2 3 4 5
```

but accidentally write:

```java
for (int i = 1; i < 5; i++)
```

Output:

```text
1
2
3
4
```

Because `i < 5` means **5 is excluded**.

Compare:

```java
i < 5
```

with:

```java
i <= 5
```

The second includes `5`.

---

### C. Incorrect conditions

Consider:

```java
int age = 15;

if (age >= 18 && age <= 60) {
    System.out.println("Allowed");
}
```

The condition is logically correct.

But if you accidentally write:

```java
if (age >= 18 || age <= 60)
```

almost every number will satisfy the condition.

Debugging means asking:

> **What values actually make this condition true?**

---

### D. Nested control flow

Example:

```java
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        System.out.println(i + ", " + j);
    }
}
```

The outer loop controls rows.

The inner loop completes **all three iterations for every outer iteration**.

Think:

```text
i = 1
    j = 1
    j = 2
    j = 3

i = 2
    j = 1
    j = 2
    j = 3

i = 3
    j = 1
    j = 2
    j = 3
```

This mental tracing technique is extremely useful when debugging nested loops.

## Part D — Trace the loop

Without running it first:

```java
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }

    System.out.println(i);
}
```

What is the exact output?

Explain what happens when `i == 3`.

## Part E — Nested loop debugging

```java
for (int row = 1; row <= 2; row++) {
    for (int column = 1; column <= 3; column++) {
        System.out.println("Row " + row + ", Column " + column);
    }

```

> How many times does the inner loop execute in total?

## Part F — Break the code

Debug this:

```java
int number = 1;

while (number <= 10) {

    if (number == 5) {
        continue;
    }

    System.out.println(number);
    number++;
}
```

Answer:

1. What happens when `number` reaches `5`?
2. Why does this create an infinite loop?
3. Fix the code.
4. Give **two different valid fixes** if you can.

---

## Part G — Final debugging challenge

Don't run this immediately. Trace it first.

```java
for (int i = 1; i <= 10; i++) {

    if (i % 2 == 0) {
        continue;
    }

    if (i > 7) {
        break;
    }

    System.out.println(i);
}
```

Answer:

1. What is the exact output?
2. Which numbers are skipped by `continue`?
3. At what value does `break` execute?
4. Why isn't that value printed?
