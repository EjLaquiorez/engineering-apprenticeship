This lesson is about **changing the normal behavior of a loop**.

---

# 1. `break`

You've already encountered `break` in traditional `switch` statements.

Inside a loop, `break` means:

> **Immediately exit the loop.**

Example:

```java
for (int number = 1; number <= 10; number++) {
    System.out.println(number);

    if (number == 5) {
        break;
    }
}
```

Output:

```text
1
2
3
4
5
```

When `number == 5`:

```java
break;
```

executes.

Java immediately leaves the loop.

It does **not** continue to `6`.

---

# 2. `break` changes the normal stopping point

Normally:

```java
for (int number = 1; number <= 10; number++) {
```

would continue until:

```text
number = 11
```

causes:

```text
11 <= 10 → false
```

But `break` gives us an **additional exit condition**.

```text
normal condition
      ↓
   continue
      ↓
   continue
      ↓
   break → STOP
```

This is useful when you've found what you're looking for.

---

# 3. Example: Searching

Suppose we have:

```java
int target = 7;

for (int number = 1; number <= 10; number++) {

    if (number == target) {
        System.out.println("Found!");
        break;
    }

}
```

Once `number` becomes `7`:

```text
Found!
```

is printed and the loop stops.

There is no reason to keep searching after finding the target.

This pattern becomes particularly useful later when we work with **arrays**.

---

# 4. `continue`

`continue` behaves differently.

It means:

> **Skip the rest of the current iteration and move to the next iteration.**

Example:

```java
for (int number = 1; number <= 5; number++) {

    if (number == 3) {
        continue;
    }

    System.out.println(number);
}
```

Output:

```text
1
2
4
5
```

When `number == 3`:

```java
continue;
```

executes.

Java skips:

```java
System.out.println(number);
```

for that iteration.

Then the loop proceeds to the next iteration.

---

# 5. `break` vs `continue`

This distinction is extremely important.

### `break`

```text
STOP THE LOOP
```

### `continue`

```text
SKIP THIS ITERATION
CONTINUE THE LOOP
```

Think:

```text
break
  ↓
EXIT

continue
  ↓
SKIP
  ↓
NEXT ITERATION
```

---

# 6. Example side by side

### `break`

```java
for (int i = 1; i <= 5; i++) {

    if (i == 3) {
        break;
    }

    System.out.println(i);
}
```

Output:

```text
1
2
```

The entire loop ends when `i == 3`.

---

### `continue`

```java
for (int i = 1; i <= 5; i++) {

    if (i == 3) {
        continue;
    }

    System.out.println(i);
}
```

Output:

```text
1
2
4
5
```

Only iteration `3` is skipped.

---

# 7. `continue` doesn't mean "stop"

This is a common beginner mistake.

Consider:

```java
for (int i = 1; i <= 5; i++) {

    if (i == 3) {
        continue;
    }

    System.out.println(i);
}
```

At `i = 3`:

```text
continue
   ↓
skip println
   ↓
update i++
   ↓
i = 4
   ↓
continue looping
```

So `continue` does **not** terminate the loop.

---

# 8. `break` in a `while` loop

`break` works with all the loops you've learned.

```java
int number = 1;

while (number <= 10) {

    if (number == 5) {
        break;
    }

    System.out.println(number);
    number++;
}
```

Output:

```text
1
2
3
4
```

Notice something interesting:

When `number == 5`, `break` happens **before** the `println`.

Therefore `5` isn't printed.

---

# 9. `continue` and updates

There's an important danger when using `continue` with `while`.

Look at this:

```java
int number = 1;

while (number <= 5) {

    if (number == 3) {
        continue;
    }

    System.out.println(number);
    number++;
}
```

⚠️ This creates an infinite loop.

Why?

When:

```text
number = 3
```

Java executes:

```java
continue;
```

and skips:

```java
number++;
```

So `number` remains `3`.

The next iteration:

```text
number = 3
```

Again:

```text
continue
```

Again:

```text
number = 3
```

Forever.

This is an important control-flow bug.

---

# 10. Safer structure

One way to avoid that problem:

```java
int number = 1;

while (number <= 5) {

    if (number == 3) {
        number++;
        continue;
    }

    System.out.println(number);
    number++;
}
```

Now when `number == 3`:

```text
number++
  ↓
number = 4
  ↓
continue
  ↓
next iteration
```

The loop can progress.
