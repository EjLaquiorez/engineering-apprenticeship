---

# 1. Why loops exist

Imagine you want to print:

```text
1
2
3
4
5
```

Without a loop:

```java
System.out.println(1);
System.out.println(2);
System.out.println(3);
System.out.println(4);
System.out.println(5);
```

That works, but imagine needing to print **1 through 1,000,000**.

We need repetition.

A `while` loop tells Java:

> **Keep executing this code while this condition is true.**

---

# 2. Basic `while` syntax

```java
while (condition) {
    // code to repeat
}
```

Example:

```java
int count = 1;

while (count <= 5) {
    System.out.println(count);
    count++;
}
```

Output:

```text
1
2
3
4
5
```

---

# 3. Understand the execution

Don't just memorize the syntax. Trace what Java actually does.

Initial state:

```text
count = 1
```

Java checks:

```text
count <= 5
1 <= 5 → true
```

Prints:

```text
1
```

Then:

```java
count++;
```

changes:

```text
count = 2
```

Java checks again:

```text
2 <= 5 → true
```

This continues until:

```text
count = 6
```

Then:

```text
6 <= 5 → false
```

The loop stops.

Think of it as:

```text
       ┌───────────────┐
       │ Check condition│
       └───────┬───────┘
               │
        true   │   false
          ↓    │     ↓
     execute   │    STOP
       body    │
          │    │
          └────┘
```

---

# 4. The three important parts

Look at this:

```java
int count = 1;

while (count <= 5) {
    System.out.println(count);
    count++;
}
```

There are three important pieces.

### 1. Initialization

```java
int count = 1;
```

Where do we start?

### 2. Condition

```java
count <= 5
```

When should the loop continue?

### 3. Update

```java
count++;
```

How does the value change so eventually the loop can stop?

A huge number of beginner loop bugs happen because one of these three pieces is missing or incorrect.

---

# 5. What happens if you forget the update?

Consider:

```java
int count = 1;

while (count <= 5) {
    System.out.println(count);
}
```

What's wrong?

`count` never changes.

It remains:

```text
1
```

So Java repeatedly checks:

```text
1 <= 5 → true
```

forever.

This is an **infinite loop**.

⚠️ Be careful when intentionally testing infinite loops. Don't let one run indefinitely.

---

# 6. Counting downward

A `while` loop doesn't have to count upward.

```java
int count = 5;

while (count >= 1) {
    System.out.println(count);
    count--;
}
```

Output:

```text
5
4
3
2
1
```

Here:

```java
count--
```

is the update.

---

# 7. `while` with user input

This is where loops start becoming useful for real programs.

For example, imagine repeatedly asking for a number until the user enters `0`.

Conceptually:

```text
Ask for number
      ↓
Is it 0?
  ↓       ↓
 yes      no
  ↓       ↓
 STOP   ask again
```

Example:

```java
Scanner scanner = new Scanner(System.in);

int number = -1;

while (number != 0) {
    System.out.print("Enter a number (0 to quit): ");
    number = scanner.nextInt();
}
```

Notice something important:

We initialize:

```java
int number = -1;
```

Why not:

```java
int number = 0;
```

Because `0` would immediately make:

```java
number != 0
```

false, so the loop would never execute.

---

# 8. `while` vs `if`

This is important.

An `if` checks a condition **once**:

```java
if (age >= 18) {
    System.out.println("Adult");
}
```

A `while` checks the condition **repeatedly**:

```java
while (count <= 5) {
    System.out.println(count);
    count++;
}
```

Think:

```text
if
→ "Should I do this?"

while
→ "Should I keep doing this?"
```
