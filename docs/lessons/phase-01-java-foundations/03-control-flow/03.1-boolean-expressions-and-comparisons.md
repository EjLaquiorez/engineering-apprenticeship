# Lesson 08 — Boolean Expressions and Comparisons

We are now starting **Topic 3 — Control Flow**.

The goal of this lesson is to understand how Java produces `true` or `false` from comparisons. These expressions will become the foundation for `if`, `while`, and other control-flow structures.

---

## Lesson Objective

By the end of this lesson, you should be able to:

* Understand what a boolean expression is.
* Use comparison operators correctly.
* Predict whether a comparison evaluates to `true` or `false`.
* Store comparison results in `boolean` variables.
* Understand the difference between `=` and `==`.
* Understand how comparisons work with numbers and characters.
* Recognize common comparison mistakes.

---

# 1. What Is a Boolean Expression?

You've already learned that a `boolean` can contain:

```java
true
false
```

A **boolean expression** is an expression that evaluates to one of those two values.

For example:

```java
int age = 25;

age >= 18
```

Java evaluates:

```text
25 >= 18
```

which produces:

```text
true
```

Therefore:

```java
boolean isAdult = age >= 18;
```

stores:

```text
isAdult → true
```

Think of it as:

```text
comparison
    ↓
true / false
    ↓
boolean value
```

---

# 2. The Comparison Operators

Java provides six basic comparison operators:

```text
==    equal to
!=    not equal to
>     greater than
<     less than
>=    greater than or equal to
<=    less than or equal to
```

Let's examine each one.

---

# 3. Equal — `==`

The `==` operator asks:

> Are these two values equal?

Example:

```java
int age = 25;

System.out.println(age == 25);
```

Java evaluates:

```text
25 == 25
```

Result:

```text
true
```

Another example:

```java
System.out.println(age == 30);
```

Java evaluates:

```text
25 == 30
```

Result:

```text
false
```

---

# 4. Not Equal — `!=`

`!=` asks:

> Are these values different?

```java
int age = 25;

System.out.println(age != 30);
```

Java evaluates:

```text
25 != 30
```

Result:

```text
true
```

But:

```java
System.out.println(age != 25);
```

produces:

```text
false
```

Because:

```text
25 != 25
```

is false.

---

# 5. Greater Than — `>`

Example:

```java
int age = 25;

System.out.println(age > 18);
```

Java evaluates:

```text
25 > 18
```

Result:

```text
true
```

But:

```java
System.out.println(age > 30);
```

produces:

```text
false
```

---

# 6. Less Than — `<`

Example:

```java
int age = 25;

System.out.println(age < 30);
```

Result:

```text
true
```

Because:

```text
25 < 30
```

is true.

But:

```java
System.out.println(age < 18);
```

produces:

```text
false
```

---

# 7. Greater Than or Equal — `>=`

This operator combines two possibilities:

```text
greater than
OR
equal
```

For example:

```java
int age = 18;

System.out.println(age >= 18);
```

Result:

```text
true
```

Because `18` is **equal to** `18`.

And:

```java
int age = 25;

System.out.println(age >= 18);
```

is also:

```text
true
```

because `25` is greater than `18`.

But:

```java
int age = 17;

System.out.println(age >= 18);
```

is:

```text
false
```

---

# 8. Less Than or Equal — `<=`

Same idea in the other direction.

```java
int age = 18;

System.out.println(age <= 18);
```

Result:

```text
true
```

Because they're equal.

And:

```java
int age = 15;

System.out.println(age <= 18);
```

is also:

```text
true
```

But:

```java
int age = 20;

System.out.println(age <= 18);
```

is:

```text
false
```

---

# 9. Comparison Results Are Boolean

This is one of the most important ideas in this lesson.

Consider:

```java
int score = 85;
```

Then:

```java
score >= 60
```

isn't an `int`.

It is a:

```text
boolean
```

because it produces:

```text
true
```

You can therefore write:

```java
boolean passed = score >= 60;
```

Now:

```text
passed → true
```

This gives us a useful pattern:

```java
boolean passed = score >= 60;
```

The variable name tells us what the condition means.

---

# 10. Boolean Expressions Can Be Printed Directly

You don't have to store the result.

You can simply write:

```java
int score = 85;

System.out.println(score >= 60);
```

Output:

```text
true
```

Java evaluates the expression before printing it.

---

# 11. `=` vs `==` — Again

This is worth reinforcing.

### `=`

Assignment:

```java
int age = 25;
```

Means:

> Put `25` into `age`.

### `==`

Comparison:

```java
age == 25
```

Means:

> Is `age` equal to `25`?

Think:

```text
=   → put something somewhere

==  → ask whether two values are equal
```

Do not confuse them.

---

# 12. Comparisons With Variables

You don't need literal values on both sides.

For example:

```java
int age = 25;
int minimumAge = 18;

boolean allowed = age >= minimumAge;
```

Java evaluates:

```text
25 >= 18
```

and stores:

```text
allowed → true
```

This is much closer to how real programs work.

---

# 13. Comparing Characters

Remember our previous lesson:

```java
char a = 'A';
char b = 'B';
```

Characters have numeric values.

Therefore:

```java
System.out.println(a < b);
```

produces:

```text
true
```

because conceptually:

```text
'A' → 65
'B' → 66

65 < 66
   ↓
true
```

You can also compare equality:

```java
System.out.println(a == 'A');
```

Result:

```text
true
```

---

# 14. Comparison Operators Don't Work the Same Way for Every Type

For now, focus primarily on numeric primitives and `char`.

For example:

```java
int a = 10;
int b = 20;

a < b
```

is valid.

And:

```java
char a = 'A';
char b = 'B';

a < b
```

is also valid.

But later we'll learn that comparing objects such as Strings requires a different approach.

For example, **don't assume**:

```java
String a = "Java";
String b = "Java";

a == b
```

means:

> "Do these Strings contain the same text?"

String comparison has its own rules, which we'll study in **Topic 6 — Strings**.

---

# 15. Expressions Can Be More Complex

A comparison can contain arithmetic.

For example:

```java
int age = 20;

boolean result = age + 5 >= 25;
```

Java evaluates the arithmetic first:

```text
20 + 5
↓
25
```

Then:

```text
25 >= 25
↓
true
```

Therefore:

```text
result → true
```

This is where your previous lessons begin connecting together:

```text
variables
   ↓
arithmetic
   ↓
comparison
   ↓
boolean
```

---

# 16. Parentheses Can Make Things Clearer

You can write:

```java
boolean result = age + 5 >= 25;
```

But you can also write:

```java
boolean result = (age + 5) >= 25;
```

The second version makes the intended order easier for a human reader to see.

Good engineering isn't just about making Java understand the code.

It's also about making **other developers understand the code**.

---

# 17. Common Mistake — Reversing the Operator

Be careful with:

```text
>
<
```

Remember:

```text
10 > 5
```

means:

> 10 is greater than 5.

While:

```text
10 < 5
```

means:

> 10 is less than 5.

A useful mental trick:

> The **wide/open side** points toward the larger value.

```text
10 > 5
```

The opening faces `10`.

---

# 18. Common Mistake — `>` vs `>=`

These are different:

```java
age > 18
```

means:

```text
18 is NOT included
```

while:

```java
age >= 18
```

means:

```text
18 IS included
```

For example:

```text
age = 18

18 > 18  → false
18 >= 18 → true
```

This distinction will become extremely important in the next lesson when we write `if` statements.

---

# 19. Common Mistake — `<` vs `<=`

Same idea:

```text
age < 18
```

doesn't include `18`.

```text
age <= 18
```

does include `18`.

So:

```text
18 < 18  → false
18 <= 18 → true
```
