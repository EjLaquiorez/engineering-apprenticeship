# Lesson 25 — Creating and Initializing Arrays

## Objective

By the end of this lesson, you should understand the difference between:

* **Declaring** an array
* **Creating** an array
* **Initializing** an array
* Creating an array with a specific size
* Initializing an array with values

---

## 1. Declaring an Array

We saw this in Lesson 24:

```java
int[] scores;
```

This is a **declaration**.

It tells Java:

> "Create a variable named `scores` that is intended to refer to an array of integers."

But we haven't actually created the array yet.

Think of it like:

```text
scores
   ↓
[ ? ][ ? ][ ? ][ ? ][ ? ]
```

Actually, at this point, there isn't an array yet.

---

# 2. Creating an Array

To actually create an array, we use `new`.

```java
int[] scores = new int[5];
```

Let's break this apart:

```text
int[]       scores       =       new int[5];
  │            │                   │
 type        variable            create
                                  array
```

### `int[]`

The array will contain integers.

### `scores`

The variable name.

### `new`

Tells Java to create something new in memory.

### `int[5]`

Create an array capable of holding **5 integers**.

So:

```java
int[] scores = new int[5];
```

creates:

```text
scores
   ↓
┌────┬────┬────┬────┬────┐
│  0 │  0 │  0 │  0 │  0 │
└────┴────┴────┴────┴────┘
```

Notice something important:

The five positions initially contain `0`.

That's because `int` arrays are automatically initialized with the default value `0`.

---

# 3. Array Size

When you write:

```java
new int[5]
```

the `5` means:

> Create **5 elements**.

For example:

```java
int[] numbers = new int[3];
```

creates:

```text
┌────┬────┬────┐
│  0 │  0 │  0 │
└────┴────┴────┘
```

And:

```java
double[] prices = new double[4];
```

creates:

```text
┌──────┬──────┬──────┬──────┐
│  0.0 │  0.0 │  0.0 │  0.0 │
└──────┴──────┴──────┴──────┘
```

---

# 4. Different Types Have Different Default Values

When Java creates an array without explicitly providing values, the elements receive default values.

For the types we're currently learning:

| Type                             | Default    |
| -------------------------------- | ---------- |
| `int`                            | `0`        |
| `double`                         | `0.0`      |
| `float`                          | `0.0`      |
| `boolean`                        | `false`    |
| `char`                           | `'\u0000'` |
| Reference types such as `String` | `null`     |

For now, the most important ones are:

```java
int[] numbers = new int[3];
```

→

```text
[0][0][0]
```

and:

```java
boolean[] statuses = new boolean[3];
```

→

```text
[false][false][false]
```

and:

```java
String[] names = new String[3];
```

→

```text
[null][null][null]
```

---

# 5. Initializing an Array With Values

There's another way to create an array.

Instead of:

```java
int[] scores = new int[5];
```

we can directly provide the values:

```java
int[] scores = {85, 90, 78, 92, 88};
```

Now the array looks like:

```text
scores
   ↓
┌────┬────┬────┬────┬────┐
│ 85 │ 90 │ 78 │ 92 │ 88 │
└────┴────┴────┴────┴────┘
```

Java automatically determines the size.

There are five values:

```text
85
90
78
92
88
```

Therefore:

```text
size = 5
```

---

# 6. Two Common Ways to Create Arrays

### Method 1 — Specify the size

```java
int[] numbers = new int[5];
```

You are saying:

> "Create an integer array with 5 positions."

Initially:

```text
[0][0][0][0][0]
```

---

### Method 2 — Provide the values

```java
int[] numbers = {10, 20, 30, 40, 50};
```

You are saying:

> "Create an integer array containing these five values."

Result:

```text
[10][20][30][40][50]
```

---

# 7. Declaration vs Creation vs Initialization

This distinction is important.

### Declaration

```java
int[] numbers;
```

You're declaring the variable.

### Creation

```java
numbers = new int[5];
```

You're creating the actual array.

### Initialization

```java
numbers = new int[] {10, 20, 30, 40, 50};
```

You're creating it and giving it initial values.

Usually, you'll combine these:

```java
int[] numbers = {10, 20, 30, 40, 50};
```

or:

```java
int[] numbers = new int[5];
```

---

# 8. You Can Declare First and Create Later

This is valid:

```java
int[] numbers;

numbers = new int[5];
```

First:

```java
int[] numbers;
```

The variable is declared.

Then:

```java
numbers = new int[5];
```

The array is created.

You can also do:

```java
numbers = new int[] {10, 20, 30, 40, 50};
```

---

# 9. A Common Beginner Mistake

Don't confuse the **size** with the **values**.

For example:

```java
int[] numbers = new int[5];
```

The `5` means:

> **5 elements**

It does **not** mean:

> Put the number `5` into the array.

The result is:

```text
[0][0][0][0][0]
```

Compare that with:

```java
int[] numbers = {5};
```

This means:

> Create an array containing one value: `5`.

Result:

```text
[5]
```

These are completely different.

---

# 10. Another Important Rule

Once the array is created with a size, its size is fixed.

For example:

```java
int[] numbers = new int[5];
```

You have:

```text
[0][0][0][0][0]
```

You can't simply add another element and make it:

```text
[0][0][0][0][0][10]
```

That same array remains size `5`.

Later, we'll learn how to **access and change the values** inside those five positions.

---

# Your Mental Model

Remember:

```text
DECLARATION

int[] numbers;
       ↓
"I have an array variable."
```

```text
CREATION

new int[5]
     ↓
"Create an array with 5 positions."
```

```text
INITIALIZATION

{10, 20, 30, 40, 50}
     ↓
"Put these initial values into the array."
```

And the common shortcut:

```java
int[] numbers = {10, 20, 30, 40, 50};
```

does all the necessary work for you.
