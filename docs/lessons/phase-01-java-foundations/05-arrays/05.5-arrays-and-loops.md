# Lesson 28 — Arrays and Loops

Now we're going to combine two things you've already learned:

* **Arrays** → store multiple values
* **Loops** → repeat code

The goal is to make array traversal **automatic**.

---

## 1. The problem with manual traversal

In Lesson 27, you did:

```java
int[] numbers = {10, 20, 30, 40, 50};

System.out.println(numbers[0]);
System.out.println(numbers[1]);
System.out.println(numbers[2]);
System.out.println(numbers[3]);
System.out.println(numbers[4]);
```

This works.

But imagine an array with **100 elements**.

You wouldn't want to write:

```java
System.out.println(numbers[0]);
System.out.println(numbers[1]);
System.out.println(numbers[2]);
// ...
System.out.println(numbers[99]);
```

This is where loops become useful.

---

# 2. Using a `for` loop

We can use:

```java
for (int i = 0; i < 5; i++) {
    System.out.println(numbers[i]);
}
```

Let's understand this carefully.

Suppose:

```java
int[] numbers = {10, 20, 30, 40, 50};
```

The loop starts with:

```java
int i = 0;
```

So:

```java
numbers[i]
```

becomes:

```java
numbers[0]
```

and prints:

```text
10
```

Then:

```java
i++
```

makes `i` become `1`.

Now:

```java
numbers[i]
```

becomes:

```java
numbers[1]
```

and prints:

```text
20
```

And so on.

### Think of it like this:

```text
i = 0 → numbers[0] → 10
i = 1 → numbers[1] → 20
i = 2 → numbers[2] → 30
i = 3 → numbers[3] → 40
i = 4 → numbers[4] → 50
```

The loop automatically moves through the indexes.

---

# 3. Why `i` is useful

`i` is just a variable.

We are using it to represent the **current index**.

For example:

```java
numbers[i]
```

If `i` is `0`:

```java
numbers[0]
```

If `i` is `1`:

```java
numbers[1]
```

If `i` is `2`:

```java
numbers[2]
```

So instead of manually changing the index ourselves, the loop changes `i`.

---

# 4. Using `.length`

Earlier, we intentionally avoided `.length`.

Now we're ready for it.

Instead of:

```java
for (int i = 0; i < 5; i++)
```

we can write:

```java
for (int i = 0; i < numbers.length; i++)
```

`numbers.length` tells us how many elements the array contains.

For:

```java
int[] numbers = {10, 20, 30, 40, 50};
```

we have:

```text
numbers.length
     ↓
     5
```

Therefore:

```java
i < numbers.length
```

is effectively:

```java
i < 5
```

The important advantage is that we don't have to manually know the array's size.

---

# 5. The complete pattern

This is an extremely important pattern:

```java
for (int i = 0; i < array.length; i++) {
    System.out.println(array[i]);
}
```

For example:

```java
int[] scores = {85, 90, 78, 92, 88};

for (int i = 0; i < scores.length; i++) {
    System.out.println(scores[i]);
}
```

Output:

```text
85
90
78
92
88
```

Notice the relationship:

```text
i              scores[i]
-------------------------
0              scores[0]
1              scores[1]
2              scores[2]
3              scores[3]
4              scores[4]
```

---

# 6. Why `i < array.length` instead of `i <= array.length`?

This is extremely important.

Our array has:

```text
length = 5
```

Valid indexes are:

```text
0  1  2  3  4
```

There is **no index 5**.

Therefore:

```java
i < numbers.length
```

means:

```text
0 < 5 ✅
1 < 5 ✅
2 < 5 ✅
3 < 5 ✅
4 < 5 ✅
5 < 5 ❌ STOP
```

But this:

```java
i <= numbers.length
```

would eventually try:

```java
numbers[5]
```

which causes:

```text
ArrayIndexOutOfBoundsException
```

Remember:

> **Array length = number of elements.**
> **Last index = length - 1.**
