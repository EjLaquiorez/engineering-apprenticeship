# Lesson 24 — What Is an Array?

### Objective

By the end of this lesson, you should be able to explain:

* What an array is
* Why arrays are useful
* How an array differs from a normal variable
* What an array stores
* Why arrays have a fixed size
* The basic mental model of an array

---

## 1. The Problem Arrays Solve

Imagine we want to store five student scores.

Without an array:

```java
int score1 = 85;
int score2 = 90;
int score3 = 78;
int score4 = 92;
int score5 = 88;
```

This works.

But imagine we have **100 students**.

We would need:

```java
int score1;
int score2;
int score3;
...
int score100;
```

That's obviously inconvenient.

An **array** lets us group multiple values of the **same type** under one variable.

Instead of:

```java
int score1 = 85;
int score2 = 90;
int score3 = 78;
int score4 = 92;
int score5 = 88;
```

we can eventually write:

```java
int[] scores = {85, 90, 78, 92, 88};
```

One variable:

```text
scores
```

containing multiple integers:

```text
85
90
78
92
88
```

---

# 2. What Is an Array?

A good beginner definition is:

> **An array is a fixed-size collection of values of the same data type, stored under one variable.**

There are several important parts here.

### Collection

It holds multiple values.

```java
int[] scores
```

can hold multiple `int` values.

### Same data type

An `int[]` stores integers.

```java
int[] scores = {85, 90, 78};
```

You can't normally put a `String` inside it:

```java
int[] scores = {85, 90, "hello"}; // ❌
```

### Fixed-size

Once an array is created with a particular size, that size doesn't change.

For example:

```java
int[] scores = new int[5];
```

creates an array capable of holding exactly **5 integers**.

You can't later turn that same array into an array of 10 integers.

We'll explore this more in Lesson 25.

---

# 3. Think of an Array Like a Row of Boxes

This is one of the most useful mental models.

Imagine:

```text
scores
   ↓

┌────┬────┬────┬────┬────┐
│ 85 │ 90 │ 78 │ 92 │ 88 │
└────┴────┴────┴────┴────┘
```

The variable:

```java
scores
```

refers to the entire collection.

Each box contains one value.

So:

```text
scores
   ↓
[85][90][78][92][88]
```

Later, we'll learn how to access individual boxes.

---

# 4. Array vs Normal Variable

A normal variable stores **one value**:

```java
int age = 25;
```

Conceptually:

```text
age
 ↓
25
```

An array stores **multiple values**:

```java
int[] ages = {18, 21, 25, 30};
```

Conceptually:

```text
ages
 ↓
[18][21][25][30]
```

So you can think of it like:

```text
Normal variable:

int age
   ↓
  25


Array:

int[] ages
   ↓
[18][21][25][30]
```

---

# 5. Arrays Have a Type

Notice this:

```java
int age;
```

versus:

```java
int[] ages;
```

The `[]` means we're declaring an **array of integers**.

Examples:

```java
int[] numbers;
double[] prices;
String[] names;
boolean[] statuses;
char[] letters;
```

Meaning:

| Declaration | Stores          |
| ----------- | --------------- |
| `int[]`     | integers        |
| `double[]`  | decimal numbers |
| `String[]`  | strings         |
| `boolean[]` | true/false      |
| `char[]`    | characters      |

The array itself has a type.

---

# 6. Arrays Can Hold Objects Too

You may remember from previous lessons that Java has types such as:

```java
String
```

So we can have:

```java
String[] names = {"John", "Maria", "Alex"};
```

Conceptually:

```text
names
  ↓
["John"]["Maria"]["Alex"]
```

Again, all elements have the same declared type: `String`.

---

# 7. A Very Important Rule

An array contains elements of the **same type**.

This:

```java
int[] numbers = {10, 20, 30, 40};
```

is valid.

But this:

```java
int[] numbers = {10, 20, "hello", 40};
```

is invalid because `"hello"` is a `String`, not an `int`.

---

# 8. Why Are Arrays Useful?

Arrays become particularly useful when you have **related data**.

For example:

```java
int[] temperatures;
```

could represent temperatures.

```java
String[] students;
```

could represent student names.

```java
double[] prices;
```

could represent product prices.

Instead of creating many unrelated variables:

```java
double price1;
double price2;
double price3;
double price4;
double price5;
```

we can group them:

```java
double[] prices;
```

This becomes extremely powerful when combined with **loops**.

And that's where we're eventually heading:

```java
for (...)
```

can process every element in an array.

But **don't worry about that yet**. We'll build toward it.

---

# 9. One Important Distinction

Don't confuse:

```java
int[] numbers;
```

with:

```java
int numbers;
```

The first means:

> `numbers` will refer to an array of integers.

The second means:

> `numbers` is one integer.

For example:

```java
int number = 10;
```

```text
number
  ↓
 10
```

while:

```java
int[] numbers = {10, 20, 30};
```

```text
numbers
   ↓
[10][20][30]
```

The `[]` is extremely important.

---

# Your First Mental Model

Remember this:

```text
VARIABLE
    ↓
  ONE VALUE

ARRAY
    ↓
MULTIPLE VALUES
    ↓
SAME TYPE
    ↓
FIXED SIZE
```

Or simply:

> **An array is one variable that represents a fixed-size group of values of the same type.**
