# Lesson 26 — Array Indexing

## 🎯 Objective

By the end of this lesson, you should be able to:

* Understand what an **index** is
* Access a specific array element
* Change a value at a specific index
* Understand why arrays start at **index 0**
* Determine the valid indexes of an array
* Avoid accessing an index that doesn't exist

---

# 1. What Is an Index?

An **index** is the position used to identify an element inside an array.

Consider:

```java
int[] scores = {85, 90, 78, 92, 88};
```

We can visualize it like this:

```text
Index:    0    1    2    3    4
         ┌────┬────┬────┬────┬────┐
Value:   │ 85 │ 90 │ 78 │ 92 │ 88 │
         └────┴────┴────┴────┴────┘
```

Each value has an index.

```text
85 → index 0
90 → index 1
78 → index 2
92 → index 3
88 → index 4
```

---

# 2. Arrays Start at Index 0

This is one of the most important rules in Java arrays:

> **The first element is at index `0`.**

Not `1`.

For:

```java
int[] scores = {85, 90, 78, 92, 88};
```

the indexes are:

```text
0 → 85
1 → 90
2 → 78
3 → 92
4 → 88
```

There are **5 elements**, but the indexes go from:

```text
0 → 4
```

---

# 3. Accessing an Element

To access an element, use:

```java
arrayName[index]
```

For example:

```java
System.out.println(scores[0]);
```

This means:

> Go to `scores`, find index `0`, and give me its value.

Output:

```text
85
```

---

### Index 1

```java
System.out.println(scores[1]);
```

Output:

```text
90
```

### Index 2

```java
System.out.println(scores[2]);
```

Output:

```text
78
```

And so on.

---

# 4. Think of Indexes as Addresses

A useful mental model is that an index is like an **address**.

```text
scores
   ↓

index       value
  0           85
  1           90
  2           78
  3           92
  4           88
```

If you ask:

```java
scores[3]
```

you're basically saying:

> "Give me the value stored at address/index 3."

Result:

```text
92
```

---

# 5. Reading vs Changing

Array indexing isn't only used for reading values.

You can also **change** a value.

Suppose:

```java
int[] scores = {85, 90, 78, 92, 88};
```

Currently:

```text
index:  0   1   2   3   4
value: 85  90  78  92  88
```

We can change index `2`:

```java
scores[2] = 95;
```

Now:

```text
index:  0   1   2   3   4
value: 85  90  95  92  88
```

The value `78` was replaced with `95`.

---

# 6. Important: Indexing Does Not Add Elements

This:

```java
scores[2] = 95;
```

doesn't create another position.

It replaces the value already at index `2`.

Before:

```text
[85][90][78][92][88]
```

After:

```text
[85][90][95][92][88]
```

Still **5 elements**.

---

# 7. Valid Indexes

Suppose:

```java
int[] numbers = new int[5];
```

There are 5 positions.

The valid indexes are:

```text
0
1
2
3
4
```

Therefore:

```java
numbers[0]   // ✅
numbers[1]   // ✅
numbers[2]   // ✅
numbers[3]   // ✅
numbers[4]   // ✅
```

But:

```java
numbers[5]
```

❌ is invalid.

Why?

Because index `5` would be asking for a **sixth position**, and the array only has five.

---

# 8. Array Size vs Last Index

This is another very important relationship.

If an array has:

```text
5 elements
```

the last index is:

```text
4
```

If an array has:

```text
10 elements
```

the last index is:

```text
9
```

If an array has:

```text
100 elements
```

the last index is:

```text
99
```

So:

> **Last index = size − 1**

We'll eventually learn a Java property called `.length` that lets us determine the size programmatically.

Not yet—save that for later.

---

# 9. Why Does Java Start at 0?

For now, don't worry about the deeper computer-science explanation.

Just establish this rule:

```text
First element  → index 0
Second element → index 1
Third element  → index 2
...
```

This means:

```java
int[] numbers = {10, 20, 30};
```

is:

```text
Index:   0    1    2
        ┌────┬────┬────┐
Value:  │ 10 │ 20 │ 30 │
        └────┴────┴────┘
```

So:

```java
numbers[0]
```

→ `10`

```java
numbers[1]
```

→ `20`

```java
numbers[2]
```

→ `30`

---

# 10. Indexing Strings

The same idea works with arrays of other types.

```java
String[] students = {"John", "Maria", "Alex"};
```

Visualize:

```text
Index:      0        1        2
          ┌────────┬────────┬────────┐
Value:    │ "John" │ "Maria"│ "Alex" │
          └────────┴────────┴────────┘
```

Therefore:

```java
System.out.println(students[0]);
```

outputs:

```text
John
```

And:

```java
System.out.println(students[2]);
```

outputs:

```text
Alex
```

---

# 11. The Big Error: ArrayIndexOutOfBoundsException

What happens if you do this?

```java
int[] numbers = {10, 20, 30};

System.out.println(numbers[3]);
```

The array has:

```text
index: 0   1   2
value: 10  20  30
```

There is no index `3`.

Java will throw an error called:

```text
ArrayIndexOutOfBoundsException
```

This is one of the most common beginner array errors.

We'll study common array errors more deeply in **Lesson 30**.

---

# 12. A Complete Example

Here's a small example using what we've learned:

```java
public class Example {

    public static void main(String[] args) {

        int[] scores = {85, 90, 78, 92, 88};

        System.out.println(scores[0]);
        System.out.println(scores[2]);

        scores[2] = 95;

        System.out.println(scores[2]);
    }
}
```

Output:

```text
85
78
95
```

What's happening?

First:

```java
scores[0]
```

→ `85`

Then:

```java
scores[2]
```

→ `78`

Then:

```java
scores[2] = 95;
```

changes the value at index `2`.

Now:

```java
scores[2]
```

→ `95`
