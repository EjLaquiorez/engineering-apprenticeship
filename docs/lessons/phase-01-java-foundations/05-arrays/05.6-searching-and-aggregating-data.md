# Lesson 29 — Searching and Aggregating Data

We're now going to use **arrays + loops** to actually process data.

So far, you've learned:

```text
Array → stores data
Index → identifies one element
Loop → visits elements automatically
```

Now we'll make the loop **do something with those elements**.

---

## 1. Searching an Array

Suppose we have:

```java
int[] numbers = {10, 20, 30, 40, 50};
```

What if we want to know:

> Does this array contain `30`?

We can traverse the array and compare each value:

```java
for (int i = 0; i < numbers.length; i++) {
    if (numbers[i] == 30) {
        System.out.println("Found!");
    }
}
```

The loop checks:

```text
numbers[0] == 30 → 10 == 30 → false
numbers[1] == 30 → 20 == 30 → false
numbers[2] == 30 → 30 == 30 → true
```

So `"Found!"` is printed.

### Important idea

The loop is **searching each element**.

```text
array
 ↓
10 → compare
20 → compare
30 → compare → FOUND
40
50
```

---

# 2. Searching Using a Variable

Hard-coding `30` isn't very useful.

Instead:

```java
int target = 30;

for (int i = 0; i < numbers.length; i++) {
    if (numbers[i] == target) {
        System.out.println("Found!");
    }
}
```

Now we can change:

```java
int target = 40;
```

and search for `40` instead.

---

# 3. Aggregating Data

**Aggregation** means combining information from multiple elements to produce one result.

For example:

```text
10 + 20 + 30 + 40 + 50
```

We can calculate the total using a variable.

Start with:

```java
int total = 0;
```

Then:

```java
for (int i = 0; i < numbers.length; i++) {
    total = total + numbers[i];
}
```

Let's follow it:

```text
Start:
total = 0

i = 0:
total = 0 + 10
total = 10

i = 1:
total = 10 + 20
total = 30

i = 2:
total = 30 + 30
total = 60

i = 3:
total = 60 + 40
total = 100

i = 4:
total = 100 + 50
total = 150
```

At the end:

```java
System.out.println(total);
```

prints:

```text
150
```

---

# 4. The Accumulator Pattern

This pattern is extremely important.

```java
int total = 0;

for (int i = 0; i < numbers.length; i++) {
    total = total + numbers[i];
}
```

`total` is called an **accumulator**.

It keeps the result accumulated so far.

You can think of it as:

```text
total
 ↓
0
 ↓ + 10
10
 ↓ + 20
30
 ↓ + 30
60
 ↓ + 40
100
 ↓ + 50
150
```

You'll see this pattern frequently in programming.

---

# 5. Finding the Largest Value

We can also use a loop to find the largest number.

Given:

```java
int[] numbers = {10, 20, 30, 40, 50};
```

We could start with:

```java
int largest = numbers[0];
```

Then compare every element:

```java
for (int i = 1; i < numbers.length; i++) {
    if (numbers[i] > largest) {
        largest = numbers[i];
    }
}
```

Notice something important:

```java
int largest = numbers[0];
```

We start with the **first element** as our current largest value.

Then we start the loop at:

```java
i = 1
```

because we've already used index `0`.

The process becomes:

```text
largest = 10

20 > 10 → largest = 20
30 > 20 → largest = 30
40 > 30 → largest = 40
50 > 40 → largest = 50
```

Final result:

```text
50
```

---

# 6. Three Important Patterns

You've now seen three fundamental array-processing patterns:

### Search

```java
if (numbers[i] == target)
```

> "Does this element match what I'm looking for?"

### Accumulate

```java
total = total + numbers[i];
```

> "Add this element to my running result."

### Find maximum

```java
if (numbers[i] > largest)
```

> "Is this element larger than my current best?"

These patterns will appear repeatedly as you progress through Java.
