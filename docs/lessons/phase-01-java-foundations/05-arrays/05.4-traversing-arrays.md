# Lesson 27 — Traversing Arrays

## 🎯 Objective

By the end of this lesson, you should understand:

* What **traversing an array** means
* How to visit every element in an array
* The difference between **accessing one element** and **traversing the entire array**
* How manual traversal works
* Why loops are useful for array traversal

We will **not use loops yet**. Loops are the focus of Lesson 28.

---

# 1. What Does "Traverse" Mean?

**Traversing an array** means:

> **Visiting each element in the array, usually from beginning to end.**

For example:

```java
int[] scores = {85, 90, 78, 92, 88};
```

The array is:

```text
Index:   0   1   2   3   4
        ┌───┬───┬───┬───┬───┐
Value:  │85 │90 │78 │92 │88 │
        └───┴───┴───┴───┴───┘
```

If we traverse the array, we visit:

```text
85 → 90 → 78 → 92 → 88
```

In terms of indexes:

```text
0 → 1 → 2 → 3 → 4
```

---

# 2. Accessing vs Traversing

This distinction is important.

### Accessing one element

```java
System.out.println(scores[2]);
```

You're accessing **one element**:

```text
78
```

### Traversing

If you visit:

```java
System.out.println(scores[0]);
System.out.println(scores[1]);
System.out.println(scores[2]);
System.out.println(scores[3]);
System.out.println(scores[4]);
```

you're visiting **every element**.

That's traversal.

---

# 3. Manual Traversal

Since we haven't introduced loops for this lesson, we can traverse an array manually.

```java
int[] scores = {85, 90, 78, 92, 88};

System.out.println(scores[0]);
System.out.println(scores[1]);
System.out.println(scores[2]);
System.out.println(scores[3]);
System.out.println(scores[4]);
```

Output:

```text
85
90
78
92
88
```

We are moving through the indexes:

```text
0
↓
1
↓
2
↓
3
↓
4
```

---

# 4. Why Manual Traversal Isn't Practical

Imagine an array has 1,000 elements.

You would need:

```java
System.out.println(numbers[0]);
System.out.println(numbers[1]);
System.out.println(numbers[2]);
// ...
System.out.println(numbers[999]);
```

That's terrible.

This is one of the reasons loops are so useful.

Instead of manually writing:

```text
0
1
2
3
4
5
...
999
```

a loop can systematically move through the indexes.

We'll learn that in **Lesson 28**.

---

# 5. Traversal Doesn't Always Mean Printing

This is an important point.

Traversing means **visiting the elements**.

What you do while visiting them can be different.

For example, you might:

### Print them

```java
System.out.println(scores[0]);
```

### Read them

```java
int score = scores[0];
```

### Compare them

```java
if (scores[0] > 90) {
    System.out.println("High score");
}
```

### Modify them

```java
scores[0] = 100;
```

So:

> **Traversal is the process of going through the elements.**

Printing is only **one possible thing you can do during traversal**.

---

# 6. Traversing From Beginning to End

The most common traversal direction is:

```text
first → last
```

For:

```java
int[] numbers = {10, 20, 30, 40};
```

we go:

```text
index 0 → index 1 → index 2 → index 3
```

or:

```text
10 → 20 → 30 → 40
```

---

# 7. You Can Also Traverse Backward

It's also possible to go from the end toward the beginning.

For:

```java
int[] numbers = {10, 20, 30, 40};
```

backward traversal would be:

```text
index 3 → index 2 → index 1 → index 0
```

giving:

```text
40 → 30 → 20 → 10
```

We'll eventually use loops to do this efficiently.

---

# 8. Traversal and Array Indexes

You should now be able to see the connection between the last two lessons.

### Lesson 26

We learned:

```java
scores[0]
scores[1]
scores[2]
```

These let us access individual elements.

### Lesson 27

We combine those accesses:

```java
scores[0]
scores[1]
scores[2]
scores[3]
scores[4]
```

That's traversal.

### Lesson 28

We'll automate that process:

```text
index 0
   ↓
index 1
   ↓
index 2
   ↓
index 3
   ↓
index 4
```

using a loop.

# 🧠 Mental Model

Think of an array as a row of houses:

```text
       0       1       2       3
    ┌──────┬──────┬──────┬──────┐
    │  10  │  20  │  30  │  40  │
    └──────┴──────┴──────┴──────┘
```

**Accessing:**

> "Go to house #2."

```java
numbers[2]
```

**Traversing:**

> "Visit every house, one after another."

```text
0 → 1 → 2 → 3
```

That's the core idea.
