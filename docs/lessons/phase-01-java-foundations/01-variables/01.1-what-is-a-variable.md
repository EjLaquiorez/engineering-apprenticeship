# Lesson 01 — What Is a Variable?

### Objective

By the end of this lesson, you should be able to explain:

* What a variable represents.
* Why programs need variables.
* The relationship between a variable, its value, and its type.
* How Java declares and assigns variables.
* The difference between **declaration**, **assignment**, and **initialization**.

We are starting with the **concept**, not memorizing syntax.

---

# 1. The Problem Variables Solve

Consider this program:

```java
System.out.println(25);
System.out.println(25);
System.out.println(25);
```

It works.

But imagine that `25` represents a user's age.

What if the user's age changes?

You would have to find every occurrence of `25` and replace it.

Instead, we can give the value a **name**:

```java
int age = 25;
```

Then:

```java
System.out.println(age);
System.out.println(age);
System.out.println(age);
```

Now the program has a way to **remember and refer to data**.

That's the fundamental purpose of a variable.

---

# 2. The Mental Model

Think of a variable as a **named storage location for a value**.

For example:

```java
int age = 25;
```

Conceptually:

```text
age
 │
 ▼
┌─────────┐
│   25    │
└─────────┘
```

The important pieces are:

```text
int    age    =    25;
 │      │     │     │
 │      │     │     └── value
 │      │     └──────── assignment
 │      └────────────── variable name
 └───────────────────── type
```

So when Java sees:

```java
int age = 25;
```

we are telling it:

> Create a variable called `age` that can hold an `int`, and give it the value `25`.

---

# 3. Variables Have Types

Java is **statically typed**.

That means a variable has a declared type.

For example:

```java
int age = 25;
double price = 19.99;
boolean loggedIn = true;
char grade = 'A';
```

Different variables hold different kinds of data.

```text
Variable       Type        Value
──────────────────────────────────
age            int         25
price          double      19.99
loggedIn       boolean     true
grade          char        A
```

The type matters.

For example:

```java
int age = 25;
```

means `age` is an integer variable.

You cannot simply do:

```java
age = "hello";
```

because `"hello"` is a `String`, not an `int`.

Java catches this kind of mistake during compilation.

---

# 4. Declaration

This:

```java
int age;
```

is a **declaration**.

You are telling Java:

> I want a variable named `age`, and its type is `int`.

But we haven't supplied a value yet.

Conceptually:

```text
age
 │
 ▼
no value assigned yet
```

---

# 5. Assignment

Now:

```java
age = 25;
```

This is **assignment**.

We are putting the value `25` into the variable.

```text
age
 │
 ▼
┌─────────┐
│   25    │
└─────────┘
```

Notice something important:

```java
int age;
age = 25;
```

is different from:

```java
int age = 25;
```

The second combines declaration and assignment.

---

# 6. Initialization

When a variable receives its first value, we call that **initialization**.

For example:

```java
int age = 25;
```

This performs:

```text
declaration
     +
initialization
```

Later, you can assign a new value:

```java
age = 30;
```

Now:

```text
Before:

age → 25

After:

age → 30
```

The variable is still called `age`.

Its **value changed**.

---

# 7. Variables Can Change

This is why they're called variables.

```java
int age = 25;

age = 26;
age = 27;
age = 28;
```

The variable remains:

```text
age
```

but its current value changes:

```text
age → 25
age → 26
age → 27
age → 28
```

A variable doesn't permanently represent one value.

It represents a **named piece of program state whose value can change**.

---

# 8. First Program

Create:

```text
Lesson01.java
```

with:

```java
public class Lesson01 {

    public static void main(String[] args) {

        int age = 25;

        System.out.println(age);

        age = 26;

        System.out.println(age);
    }
}
```

Compile:

```bash
javac Lesson01.java
```

Run:

```bash
java Lesson01
```

Expected output:

```text
25
26
```

---

# 9. Observe What Actually Happened

The important part isn't the syntax.

Trace the program:

```java
int age = 25;
```

State:

```text
age → 25
```

Then:

```java
System.out.println(age);
```

Output:

```text
25
```

Then:

```java
age = 26;
```

State changes:

```text
age → 26
```

Then:

```java
System.out.println(age);
```

Output:

```text
26
```

This is the beginning of understanding **program state**.

6. Change the score to `100`.


You should use **one variable** called `score`.

