# Lesson 33 — Searching and Manipulating Strings

Today we'll learn six useful String methods:

```java
contains()
startsWith()
endsWith()
indexOf()
replace()
trim()
```

These are useful when your program needs to **inspect or clean text**.

---

## 1. `contains()`

`contains()` asks:

> "Does this String contain this piece of text?"

Example:

```java
String message = "Hello World";

System.out.println(message.contains("World"));
```

Output:

```text
true
```

Because `"World"` exists inside `"Hello World"`.

But:

```java
System.out.println(message.contains("Java"));
```

produces:

```text
false
```

### Important

`contains()` is **case-sensitive**.

```java
String message = "Hello World";

System.out.println(message.contains("world"));
```

produces:

```text
false
```

because:

```text
World
world
```

are different capitalization.

---

# 2. `startsWith()`

Checks whether a String **begins with** particular text.

```java
String filename = "report.txt";

System.out.println(filename.startsWith("report"));
```

Output:

```text
true
```

But:

```java
System.out.println(filename.startsWith("txt"));
```

Output:

```text
false
```

Think:

```text
report.txt
^^^^^^
starts here
```

---

# 3. `endsWith()`

The opposite idea.

It checks whether the String **ends with** particular text.

```java
String filename = "report.txt";

System.out.println(filename.endsWith(".txt"));
```

Output:

```text
true
```

This is useful for things like checking file extensions:

```java
if (filename.endsWith(".pdf")) {
    System.out.println("PDF file");
}
```

---

# 4. `indexOf()`

`indexOf()` tells you the **index where a character or piece of text first appears**.

Example:

```java
String word = "banana";

System.out.println(word.indexOf("a"));
```

Output:

```text
1
```

Because:

```text
b a n a n a
0 1 2 3 4 5
  ↑
```

The first `"a"` is at index `1`.

Another example:

```java
System.out.println(word.indexOf("nan"));
```

Output:

```text
2
```

because:

```text
b a n a n a
0 1 2 3 4 5
    ↑
    nan
```

### What if it doesn't exist?

```java
System.out.println(word.indexOf("z"));
```

Output:

```text
-1
```

This is important:

> `indexOf()` returns `-1` when the searched text cannot be found.

So you can do:

```java
if (word.indexOf("z") == -1) {
    System.out.println("Not found");
}
```

---

# 5. `replace()`

`replace()` creates a String with one piece of text replaced by another.

```java
String message = "Hello World";

String newMessage = message.replace("World", "Java");

System.out.println(newMessage);
```

Output:

```text
Hello Java
```

Notice again:

```java
String newMessage = message.replace("World", "Java");
```

We store the result.

Just like `toUpperCase()`, the original String isn't changed.

---

# 6. `trim()`

`trim()` removes whitespace from the **beginning and end** of a String.

Example:

```java
String username = "   admin   ";

System.out.println(username.trim());
```

Output:

```text
admin
```

Think:

```text
"   admin   "
^^^       ^^^
removed
```

But `trim()` does **not** remove spaces in the middle:

```java
String name = "Justine Laquiorez";

System.out.println(name.trim());
```

The space between the first and last name remains.

---

# Let's put them together

Imagine a user enters:

```java
String input = "   Hello Java World   ";
```

We could clean it:

```java
String cleaned = input.trim();
```

Then check:

```java
System.out.println(cleaned.contains("Java"));
```

Output:

```text
true
```

We can also manipulate it:

```java
System.out.println(cleaned.replace("Java", "Programming"));
```

Output:

```text
Hello Programming World
```

This is the beginning of **text processing**.
