## 1. Problem: Count a Character

Suppose we have:

```java
String word = "banana";
```

We want to know how many times `"a"` appears.

We can use:

```java
word.charAt(i)
```

inside a loop.

```java
int count = 0;

for (int i = 0; i < word.length(); i++) {
    if (word.charAt(i) == 'a') {
        count++;
    }
}

System.out.println("Count: " + count);
```

Output:

```text
Count: 3
```

Notice we're combining things you've already learned:

```text
String
 ↓
length()
 ↓
for loop
 ↓
charAt()
 ↓
if
 ↓
counter
```

## 2. Searching Text

We can also use `contains()` to validate something.

```java
String email = "user@example.com";

if (email.contains("@")) {
    System.out.println("Valid email format");
} else {
    System.out.println("Invalid email format");
}
```

This isn't a complete email validator, but it demonstrates the idea of **using String operations to make decisions**.

## 3. Basic Text Processing

Let's say we receive:

```java
String input = "   Java Programming   ";
```

We can clean it first:

```java
String cleaned = input.trim();
```

Then transform it:

```java
cleaned = cleaned.toUpperCase();
```

Then inspect it:

```java
System.out.println(cleaned);
System.out.println(cleaned.length());
```

Output:

```text
JAVA PROGRAMMING
16
```

We're creating a small processing pipeline:

```text
raw input
   ↓
trim()
   ↓
toUpperCase()
   ↓
process
```

# 4. Combining `split()` + Loops + String Methods

This is where Lesson 34 becomes useful.

Consider:

```java
String names = "alice,bob,charlie";
```

We can split it:

```java
String[] namesArray = names.split(",");
```

Then process every name:

```java
for (int i = 0; i < namesArray.length; i++) {
    namesArray[i] = namesArray[i].toUpperCase();
}
```

Now the array contains:

```text
ALICE
BOB
CHARLIE
```

We're modifying each element individually.
