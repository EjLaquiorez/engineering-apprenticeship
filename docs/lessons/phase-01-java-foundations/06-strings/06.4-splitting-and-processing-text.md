# Lesson 34 — Splitting and Processing Text

We’ll continue directly from Lesson 33. No need to revisit the previous lessons.

## 1. What is `split()`?

So far, we've worked with a String as **one piece of text**:

```java
String names = "John,Maria,Alex";
```

But sometimes we want to break that String into individual pieces:

```text
John
Maria
Alex
```

That's what `split()` does.

### Basic syntax

```java
String[] parts = text.split("delimiter");
```

For example:

```java
String names = "John,Maria,Alex";

String[] parts = names.split(",");
```

The comma tells Java:

> "Whenever you find a comma, split the String here."

The result is an **array**:

```text
parts[0] → "John"
parts[1] → "Maria"
parts[2] → "Alex"
```

Notice something important:

**`split()` produces a `String[]`, not a single `String`.**

---

## 2. Splitting a sentence

You can also split using a space:

```java
String sentence = "Java is fun";

String[] words = sentence.split(" ");
```

Now:

```text
words[0] → "Java"
words[1] → "is"
words[2] → "fun"
```

The delimiter is `" "` — one space.

---

## 3. Processing the pieces

Because `split()` gives us an array, we can use a loop to process every piece.

```java
String sentence = "Java is fun";

String[] words = sentence.split(" ");

for (int i = 0; i < words.length; i++) {
    System.out.println(words[i]);
}
```

Output:

```text
Java
is
fun
```

This connects directly to what you learned in **Topic 5 — Arrays**.

The flow is:

```text
String
   ↓
split()
   ↓
String[]
   ↓
loop through array
   ↓
process each piece
```

---

## 4. `split()` with `length`

Remember that an array has `.length`:

```java
String sentence = "Java is fun";

String[] words = sentence.split(" ");

System.out.println(words.length);
```

Output:

```text
3
```

Because there are three pieces:

```text
Java
is
fun
```

---

# 5. Processing each piece

We can do something with each word.

For example:

```java
String sentence = "java is fun";

String[] words = sentence.split(" ");

for (int i = 0; i < words.length; i++) {
    System.out.println(words[i].toUpperCase());
}
```

Output:

```text
JAVA
IS
FUN
```

Here we're combining several things you've already learned:

* `split()` → breaks text apart
* arrays → stores the pieces
* `for` → visits each piece
* `toUpperCase()` → transforms each piece

That's exactly what **processing text** means.

---

# 6. Combining Strings

What if we want to put Strings together?

You've already seen concatenation:

```java
String firstName = "John";
String lastName = "Smith";

String fullName = firstName + " " + lastName;
```

Result:

```text
John Smith
```

We can also build a String while processing an array:

```java
String[] words = {"Java", "is", "fun"};

String result = "";

for (int i = 0; i < words.length; i++) {
    result = result + words[i] + " ";
}

System.out.println(result);
```

Output:

```text
Java is fun
```

The important idea is:

```text
pieces → process → combine
```

---

# 7. Mini Example

Let's look at a realistic example.

```java
String data = "apple,banana,orange";

String[] fruits = data.split(",");

for (int i = 0; i < fruits.length; i++) {
    System.out.println("Fruit: " + fruits[i]);
}
```

Output:

```text
Fruit: apple
Fruit: banana
Fruit: orange
```

Notice that the comma itself is **not included** in the resulting pieces.
