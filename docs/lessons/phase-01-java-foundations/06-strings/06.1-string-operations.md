# 1. What is a `String`?

A `String` represents **text**.

For example:

```java
String name = "Justine";
String city = "Manila";
String message = "Hello World";
```

Unlike:

```java
int age = 25;
double price = 99.99;
boolean active = true;
```

a `String` stores a sequence of characters.

Think of it like this:

```text
"Hello"
 ↓
 H e l l o
 0 1 2 3 4
```

Each character has a position called an **index**.

Just like arrays, String indexes start at **0**.

So:

```text
String: "Hello"

Index:   0 1 2 3 4
         H e l l o
```

This becomes important when we use `charAt()`.

---

# 2. `length()`

`length()` tells us how many characters are in the String.

```java
String name = "Justine";

System.out.println(name.length());
```

Output:

```text
7
```

Why?

```text
J u s t i n e
0 1 2 3 4 5 6
```

There are **7 characters**.

### Important distinction

With arrays, we used:

```java
numbers.length
```

With Strings, we use:

```java
name.length()
```

Notice the parentheses.

```text
Array:
numbers.length

String:
name.length()
```

The reason is that `length()` is a **method**.

---

# 3. `charAt()`

`charAt()` retrieves a single character at a particular index.

```java
String name = "Justine";

System.out.println(name.charAt(0));
```

Output:

```text
J
```

Because:

```text
J u s t i n e
0 1 2 3 4 5 6
↑
```

We can also do:

```java
System.out.println(name.charAt(3));
```

Output:

```text
t
```

### Important

`charAt()` returns a **`char`**, not a String.

```java
char firstLetter = name.charAt(0);
```

---

# 4. `substring()`

`substring()` allows us to extract part of a String.

Example:

```java
String name = "Justine";

System.out.println(name.substring(0, 4));
```

Output:

```text
Just
```

The important rule is:

```java
substring(start, end)
```

The `start` index is included.

The `end` index is **not included**.

So:

```text
J u s t i n e
0 1 2 3 4 5 6

substring(0, 4)

0 → J  included
1 → u  included
2 → s  included
3 → t  included
4 → i  STOP before this
```

Result:

```text
Just
```

This is another place where **off-by-one errors** can happen.

---

# 5. `toUpperCase()`

Converts the String to uppercase.

```java
String name = "Justine";

System.out.println(name.toUpperCase());
```

Output:

```text
JUSTINE
```

---

# 6. `toLowerCase()`

Converts the String to lowercase.

```java
String name = "JUSTINE";

System.out.println(name.toLowerCase());
```

Output:

```text
justine
```

---

# 7. Important: Strings are not modified in place

Look at this:

```java
String name = "Justine";

name.toUpperCase();

System.out.println(name);
```

What do you think happens?

It prints:

```text
Justine
```

Why?

Because:

```java
name.toUpperCase();
```

creates a converted String, but we didn't store the result.

We would need:

```java
name = name.toUpperCase();
```

Now:

```java
System.out.println(name);
```

prints:

```text
JUSTINE
```

This idea will become very important when working with Strings.
