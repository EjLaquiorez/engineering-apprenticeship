# Lesson 32 — Comparing Strings

## 1. The problem

You already know that with numbers we can use:

```java
int age1 = 25;
int age2 = 25;

System.out.println(age1 == age2);
```

Output:

```text
true
```

So you might naturally think we can do the same with Strings:

```java
String name1 = "Justine";
String name2 = "Justine";

System.out.println(name1 == name2);
```

Sometimes this can produce `true`, which makes the problem confusing.

**For Strings, `==` is not the correct tool for asking whether two Strings contain the same text.**

---

# 2. `equals()`

When we want to compare the **contents** of Strings, use:

```java
.equals()
```

Example:

```java
String name1 = "Justine";
String name2 = "Justine";

System.out.println(name1.equals(name2));
```

Output:

```text
true
```

We're asking:

> "Does the String stored in `name1` contain the same text as the String stored in `name2`?"

---

# 3. Different text

```java
String name1 = "Justine";
String name2 = "Alexander";

System.out.println(name1.equals(name2));
```

Output:

```text
false
```

Because:

```text
Justine
   ≠
Alexander
```

---

# 4. Why `==` is different

This is the important concept.

For objects such as Strings:

```java
==
```

checks whether the two references refer to the **same object**, rather than reliably checking whether their text is the same.

Whereas:

```java
.equals()
```

checks the **content**.

Think of it like:

```text
==

"Are these the same object?"

.equals()

"Do these objects contain the same text?"
```

For now, don't worry about mastering Java's entire memory/reference model. The practical rule is:

> **Use `.equals()` when comparing String contents.**

---

# 5. `equalsIgnoreCase()`

What if capitalization is different?

```java
String name1 = "Justine";
String name2 = "JUSTINE";

System.out.println(name1.equals(name2));
```

Output:

```text
false
```

Because Java considers:

```text
Justine
JUSTINE
```

different capitalization.

If capitalization shouldn't matter, use:

```java
System.out.println(name1.equalsIgnoreCase(name2));
```

Output:

```text
true
```

So:

```text
equals()
       ↓
case-sensitive

equalsIgnoreCase()
       ↓
case-insensitive
```

---

# 6. A realistic example

Imagine a login program:

```java
String username = "admin";
String input = "admin";

if (username.equals(input)) {
    System.out.println("Login successful");
}
```

This makes sense because we're asking:

> Does the entered username contain the same text as the stored username?

Another example:

```java
String answer = "YES";

if (answer.equalsIgnoreCase("yes")) {
    System.out.println("You answered yes.");
}
```

This accepts:

```text
yes
YES
Yes
yEs
YeS
```

because capitalization is ignored.
