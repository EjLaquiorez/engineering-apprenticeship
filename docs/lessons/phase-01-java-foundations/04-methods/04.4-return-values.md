# Lesson 20 — Return Values

So far, we've learned that a method can **receive information** through parameters:

```java
displayStudent("Justine", 27, 'S');
```

The flow is:

```text
Arguments
    ↓
  Method
    ↓
  Action
```

But what if we want the method to **calculate something and give the result back**?

That's what a **return value** is for.

---

## 1. A Method Can Give Something Back

Imagine:

```java
static int add(int first, int second) {
    return first + second;
}
```

This method receives:

```text
first  → int
second → int
```

It calculates:

```text
first + second
```

And then gives the answer back:

```text
return
   ↓
result
```

We can call it like this:

```java
int result = add(10, 5);
```

Now:

```text
10 + 5
  ↓
 15
  ↓
result
```

So `result` contains:

```text
15
```

---

# 2. What Does `return` Do?

Look at:

```java
static int add(int first, int second) {
    return first + second;
}
```

This:

```java
return first + second;
```

means:

> Calculate `first + second` and send that value back to whoever called the method.

For:

```java
int result = add(10, 5);
```

Java effectively gets:

```text
add(10, 5)
    ↓
10 + 5
    ↓
15
    ↓
int result
```

---

# 3. Why Is It `int`?

Notice this:

```java
static int add(...)
```

Previously, we used:

```java
static void displayStudent(...)
```

Now we're using:

```java
static int add(...)
```

The difference is important.

```text
void
 ↓
method doesn't return a value

int
 ↓
method returns an int
```

Since:

```java
return first + second;
```

produces an integer, the method says:

```java
static int
```

It is essentially declaring:

> "This method will return an `int`."

---

# 4. Return Type Must Match

For example:

```java
static int calculateAge() {
    return 27;
}
```

This works because:

```text
return value → int
method type  → int
```

But imagine:

```java
static int getName() {
    return "Justine";
}
```

That doesn't work.

Why?

```text
Method promises → int
Actually returns → String
```

The return type tells Java what kind of value the method is expected to give back.

---

# 5. Return Values Can Be Different Types

This is where your previous knowledge of data types becomes useful.

### `int`

```java
static int getAge() {
    return 27;
}
```

### `double`

```java
static double getPrice() {
    return 1499.99;
}
```

### `boolean`

```java
static boolean isAdult() {
    return true;
}
```

### `char`

```java
static char getGrade() {
    return 'A';
}
```

### `String`

```java
static String getName() {
    return "Justine";
}
```

The general pattern is:

```text
static RETURN_TYPE methodName(parameters) {
    return VALUE;
}
```

For example:

```java
static int calculateTotal(int price, int quantity) {
    return price * quantity;
}
```

---

# 6. Returning Doesn't Mean Printing

This is a very important distinction.

Consider:

```java
static int add(int a, int b) {
    return a + b;
}
```

The method does **not** print anything.

It gives the value back.

We can then decide what to do with that value:

```java
int result = add(10, 5);

System.out.println(result);
```

Output:

```text
15
```

The flow is:

```text
add(10, 5)
     ↓
   return
     ↓
    15
     ↓
result
     ↓
println(result)
     ↓
   screen
```

The method's job is to **calculate and return**.

The caller's job can be to **print the result**.

This separation is extremely useful.

---

# 7. You Can Use the Returned Value Directly

You don't always need a variable.

This is also valid:

```java
System.out.println(add(10, 5));
```

Flow:

```text
add(10, 5)
    ↓
   15
    ↓
println(15)
    ↓
  screen
```

---

# 8. Return Values + Parameters

Now combine what we learned in Lesson 19 with today's lesson.

```java
static int calculateTotal(int price, int quantity) {
    return price * quantity;
}
```

The method has:

```text
INPUT
 ↓
price
quantity
```

and:

```text
OUTPUT
 ↓
total
```

For example:

```java
int total = calculateTotal(100, 3);
```

Conceptually:

```text
100 ───────→ price
             │
3 ─────────→ quantity
             │
             ↓
       price * quantity
             ↓
            300
             ↓
          return
             ↓
           total
```

This is a major pattern in programming:

```text
INPUT → PROCESS → OUTPUT
```

Methods give us a clean way to represent that.

---

# 9. `return` Also Ends the Method

Consider:

```java
static int add(int a, int b) {

    int result = a + b;

    return result;

    // code here would not execute
}
```

Once Java reaches:

```java
return result;
```

the method is finished.

The value goes back to the caller.

So:

```java
return
```

has two jobs:

1. **Send a value back**
2. **End the method's execution**

We'll practice this more when we get into control flow inside methods.

---

# 10. Don't Confuse `return` With `System.out.println`

These are very different:

```java
System.out.println(result);
```

means:

> Display this on the console.

While:

```java
return result;
```

means:

> Give this value back to the caller and end the method.

For example:

```java
static int add(int a, int b) {

    return a + b;

}
```

The method doesn't display anything.

But:

```java
int answer = add(5, 3);
```

allows another part of the program to receive the `8`.
