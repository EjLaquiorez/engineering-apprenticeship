# Lesson 22 — Method Scope and Local Variables

### Objective

By the end of this lesson, you should understand:

* What a local variable is
* Where a local variable exists
* How method scope works
* Why one method cannot directly access another method's local variables
* Common scope mistakes

---

## 1. What is a local variable?

A **local variable** is a variable declared inside a method or block.

For example:

```java
static void calculateTotal() {
    double total = 100.50;
}
```

`total` is a **local variable**.

It belongs to the `calculateTotal()` method.

Think of it like:

```text
calculateTotal()
│
├── price
├── quantity
└── total
```

Those variables exist within that method's scope.

---

## 2. A method has its own scope

Consider:

```java
static void methodA() {
    int number = 10;
}

static void methodB() {
    System.out.println(number);
}
```

Will this work?

❌ No.

`number` belongs to `methodA()`.

`methodB()` cannot directly access it.

```text
methodA()
┌─────────────────┐
│ int number = 10 │
└─────────────────┘
         ↓
    belongs here


methodB()
┌──────────────────────┐
│ System.out.println() │
│        number ❌      │
└──────────────────────┘
```

The variable doesn't exist within `methodB()`'s scope.

---

# 3. Parameters are also local variables

This is important.

Look at:

```java
static void displayStudent(String name, int age) {
    System.out.println(name);
    System.out.println(age);
}
```

`name` and `age` are parameters.

But from a scope perspective, they are **local to that method**.

They can be used here:

```java
static void displayStudent(String name, int age) {
    System.out.println(name); // ✅
    System.out.println(age);  // ✅
}
```

But not here:

```java
static void displayStudent(String name, int age) {
    System.out.println(name);
}

static void displayAge() {
    System.out.println(age); // ❌
}
```

`age` belongs to `displayStudent()`.

---

# 4. Scope vs lifetime

For now, keep the distinction simple:

### Scope

**Where can I access this variable?**

### Lifetime

**How long does this variable exist?**

For example:

```java
static void calculate() {
    int total = 100;
}
```

`total` is accessible only inside `calculate()`.

When that method finishes, that local variable's lifetime ends as well.
