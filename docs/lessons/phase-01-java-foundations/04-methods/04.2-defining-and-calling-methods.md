# Lesson 18 — Defining and Calling Methods

## Lesson Goal

By the end of this lesson, you should understand:

* What it means to **define** a method
* What it means to **call** a method
* The basic anatomy of a method
* What the method name does
* What `()` represents at this stage
* What `{ }` represents
* Why `static` appears in our examples
* The difference between a method definition and a method call

We are **not** going deeply into parameters or return values yet. Those have their own lessons.

---

# 1. Start With What You Already Know

You created this:

```java
static void displayWelcome() {
    System.out.println("Hello there!");
}
```

And called it:

```java
displayWelcome();
```

Let's now understand exactly what we're looking at.

---

# 2. Anatomy of a Basic Method

Look at:

```java
static void displayWelcome() {
    System.out.println("Hello there!");
}
```

For now, mentally divide it like this:

```text
static   void   displayWelcome()   {
  │       │            │            │
  │       │            │            └── method body begins
  │       │            └─────────────── method name
  │       └──────────────────────────── return type
  └──────────────────────────────────── modifier
```

And then:

```text
}
↑
method body ends
```

Don't worry if `static` and `void` aren't completely clear yet. We're going to address them individually.

---

# 3. The Method Name

This part:

```java
displayWelcome
```

is the **method name**.

Just like a variable has a name:

```java
int age = 25;
```

a method has a name:

```java
displayWelcome()
```

The name should communicate what the method does.

Good:

```java
displayMenu()
calculateTotal()
validateInput()
displayWelcome()
```

Bad:

```java
thing()
doStuff()
abc()
method1()
```

A method name is part of how humans understand the program.

---

# 4. The Parentheses `()`

You have seen:

```java
displayWelcome()
```

The parentheses are part of the method structure.

For now, we're using empty parentheses:

```java
()
```

That means our method currently doesn't receive any information from the caller.

For example:

```java
displayWelcome();
```

No information is being passed.

Later, you'll see:

```java
displayWelcome("Justine");
```

and:

```java
calculateTotal(100, 50);
```

That's where **parameters and arguments** become important.

But that's **Lesson 19**.

For now:

```text
()
↓
method receives no arguments
```

---

# 5. The Curly Braces `{ }`

Look at:

```java
static void displayWelcome() {

    System.out.println("Hello there!");

}
```

Everything between:

```java
{
```

and:

```java
}
```

is the **method body**.

The method body contains the instructions the method performs.

So:

```java
static void displayWelcome() {

    System.out.println("Hello there!");

}
```

can be understood as:

```text
method name
     ↓
displayWelcome()
     ↓
"Here is the responsibility"
     ↓
{
    perform the responsibility
}
```

---

# 6. Defining a Method

When you write:

```java
static void displayWelcome() {
    System.out.println("Hello there!");
}
```

you are **defining** the method.

You're telling Java:

> "There is a method called `displayWelcome`, and this is what it does."

You're not executing it yet.

Think of it like creating a recipe:

```text
DEFINE RECIPE
    ↓
Here's how to make the dish.
```

The recipe existing doesn't mean you've cooked the dish.

---

# 7. Calling a Method

When you write:

```java
displayWelcome();
```

you are **calling** the method.

You're telling Java:

> "Execute `displayWelcome` now."

So:

```text
DEFINE

static void displayWelcome() {
    System.out.println("Hello!");
}
```

means:

> Here's what the method does.

While:

```text
CALL

displayWelcome();
```

means:

> Do it now.

This distinction is fundamental.

---

# 8. One Definition, Multiple Calls

Here's something useful:

```java
public class Lesson18Example {

    static void sayHello() {
        System.out.println("Hello!");
    }

    public static void main(String[] args) {

        sayHello();
        sayHello();
        sayHello();

    }
}
```

Output:

```text
Hello!
Hello!
Hello!
```

We defined the logic **once**:

```java
static void sayHello() {
    System.out.println("Hello!");
}
```

But called it three times:

```java
sayHello();
sayHello();
sayHello();
```

This is one of the reasons methods are useful.

---

# 9. What Is `void`?

You've already used:

```java
static void sayHello()
```

Let's introduce `void` now, but don't worry—we have a dedicated lesson for it later.

`void` is the method's **return type**.

It means:

> This method does not return a value.

For example:

```java
static void sayHello() {
    System.out.println("Hello!");
}
```

The method performs an action:

```text
sayHello()
   ↓
prints "Hello!"
```

It doesn't give us a value to store.

Compare that with something we'll learn later:

```java
static int calculateSomething() {
    // eventually returns an int
}
```

Here:

```text
void
 ↓
returns no value

int
 ↓
returns an integer value
```

We'll properly learn how this works in **Lesson 20 — Return Values** and **Lesson 21 — `void` Methods**.

So don't worry about mastering it yet.

---

# 10. What Is `static`?

You've also been writing:

```java
static void sayHello()
```

We need to address this because I don't want you blindly memorizing it.

For our current procedural Java programs, `static` allows us to call the method directly from `main()`:

```java
public static void main(String[] args) {

    sayHello();

}
```

without creating an object first.

For Phase 01, you can think of it as:

> **We're making this method available to our `static` `main()` so we can call it directly.**

There is a deeper meaning to `static`, but **we don't need that complexity yet**.

And importantly:

**`static` is not what makes something a method.**

This:

```java
static void sayHello()
```

is a method because it has the method structure.

We'll revisit `static` when object-oriented Java becomes relevant.

---

# 11. Put Everything Together

Now you can read:

```java
static void displayWelcome() {

    System.out.println("Hello there!");

}
```

as:

```text
static
  ↓
available to our static context

void
  ↓
returns no value

displayWelcome
  ↓
method's name

()
  ↓
currently accepts no arguments

{
    ...
}
  ↓
method body
```

You don't need to memorize this as a single giant definition.

Understand what each piece represents.

---

# 12. Full Example

```java
public class Lesson18Example {

    static void displayWelcome() {
        System.out.println("Hello there!");
    }

    static void displayGoodbye() {
        System.out.println("Goodbye!");
    }

    public static void main(String[] args) {

        displayWelcome();

        System.out.println("Program is running...");

        displayGoodbye();

    }
}
```

Execution:

```text
main()
  ↓
displayWelcome()
  ↓
Hello there!
  ↓
System.out.println(...)
  ↓
Program is running...
  ↓
displayGoodbye()
  ↓
Goodbye!
```

Notice that `main()` is acting almost like a coordinator:

```text
main()
 ├── displayWelcome()
 ├── do something
 └── displayGoodbye()
```

This is exactly the concept we established in Lesson 17.
