# Lesson 19 — Parameters and Arguments

## Lesson Goal

Today we're answering one important question:

> **How can we give information to a method?**

So far, you've created methods like:

```java
static void displayUser() {
    System.out.println("User: Maya");
}
```

and called them:

```java
displayUser();
```

But what if we don't want the method to always display **Maya**?

What if we want:

```text
User: Maya
User: Alex
User: John
```

using the **same method**?

That's where parameters come in.

---

# 1. The Problem

Without parameters, we might write:

```java
static void displayMaya() {
    System.out.println("User: Maya");
}

static void displayAlex() {
    System.out.println("User: Alex");
}

static void displayJohn() {
    System.out.println("User: John");
}
```

This works, but we're creating separate methods for essentially the same responsibility.

That's not ideal.

We really want **one method**:

```text
displayUser(...)
```

that can work with different names.

---

# 2. Giving Information to a Method

We can write:

```java
static void displayUser(String name) {
    System.out.println("User: " + name);
}
```

Now something new appears:

```java
String name
```

This is called a **parameter**.

Think of the method as a machine:

```text
                 INPUT
                   ↓
             ┌───────────┐
             │           │
             │ display   │
             │   User    │
             │           │
             └───────────┘
                   ↓
                 OUTPUT
```

The parameter is the **input slot**.

---

# 3. What Is a Parameter?

In:

```java
static void displayUser(String name) {
    System.out.println("User: " + name);
}
```

this:

```java
String name
```

is the **parameter**.

It says:

> This method expects to receive a `String`, and inside this method we'll refer to that value using the name `name`.

So:

```text
String
  ↓
type of information expected

name
  ↓
local name we use for that information
```

---

# 4. What Is an Argument?

Now look at the call:

```java
displayUser("Maya");
```

The value:

```java
"Maya"
```

is called an **argument**.

So we have:

### Parameter

Defined in the method:

```java
static void displayUser(String name)
```

### Argument

Provided when calling the method:

```java
displayUser("Maya");
```

The easiest way to remember the difference:

```text
PARAMETER
↓
placeholder in the method definition

ARGUMENT
↓
actual value provided during the call
```

---

# 5. Watch What Happens

Here's the complete program:

```java
public class Lesson19Example {

    static void displayUser(String name) {
        System.out.println("User: " + name);
    }

    public static void main(String[] args) {

        displayUser("Maya");
        displayUser("Alex");
        displayUser("John");

    }
}
```

Output:

```text
User: Maya
User: Alex
User: John
```

We defined the method **once**:

```java
static void displayUser(String name) {
    System.out.println("User: " + name);
}
```

But we called it three times with different arguments:

```java
displayUser("Maya");
displayUser("Alex");
displayUser("John");
```

This is a powerful idea.

---

# 6. What Happens to `"Maya"`?

When Java executes:

```java
displayUser("Maya");
```

you can mentally think of it as:

```text
"Maya"
   ↓
name
   ↓
System.out.println("User: " + name);
   ↓
User: Maya
```

Then:

```java
displayUser("Alex");
```

becomes conceptually:

```text
"Alex"
   ↓
name
   ↓
System.out.println("User: " + name);
   ↓
User: Alex
```

The method's logic stays the same.

Only the input changes.

---

# 7. Parameters Can Have Different Types

This is important because you're already familiar with Java primitive types.

A parameter has a **type**.

For example:

### `int`

```java
static void displayAge(int age) {
    System.out.println("Age: " + age);
}
```

Call:

```java
displayAge(25);
```

---

### `double`

```java
static void displayPrice(double price) {
    System.out.println("Price: " + price);
}
```

Call:

```java
displayPrice(1499.99);
```

---

### `boolean`

```java
static void displayStatus(boolean active) {
    System.out.println("Active: " + active);
}
```

Call:

```java
displayStatus(true);
```

---

### `char`

```java
static void displayGrade(char grade) {
    System.out.println("Grade: " + grade);
}
```

Call:

```java
displayGrade('A');
```

---

### `String`

```java
static void displayName(String name) {
    System.out.println("Name: " + name);
}
```

Call:

```java
displayName("Maya");
```

Notice the pattern:

```text
static void methodName(TYPE parameterName)
```

For example:

```text
static void displayAge(int age)
                         ↑
                       parameter
```

---

# 8. The Argument Must Match the Parameter

Suppose we have:

```java
static void displayAge(int age) {
    System.out.println("Age: " + age);
}
```

This is valid:

```java
displayAge(25);
```

because:

```text
parameter → int
argument  → 25
```

But this is not appropriate:

```java
displayAge("Maya");
```

because:

```text
parameter → int
argument  → String
```

The method expects an integer, but we're giving it text.

This is similar to what you experienced when you wrote:

```java
displayMenu(10);
```

for a method defined as:

```java
displayMenu();
```

The method's definition determines what kind of information it accepts.

---

# 9. Multiple Parameters

A method can receive more than one piece of information.

For example:

```java
static void displayPerson(String name, int age) {
    System.out.println("Name: " + name);
    System.out.println("Age: " + age);
}
```

Call it:

```java
displayPerson("Maya", 25);
```

Here we have:

```text
PARAMETERS

String name
int age


ARGUMENTS

"Maya"
25
```

They match by **position**:

```text
"Maya"  → String name
  25    → int age
```

Order matters.

---

# 10. Another Example

```java
static void addNumbers(int firstNumber, int secondNumber) {

    int result = firstNumber + secondNumber;

    System.out.println(result);
}
```

Call:

```java
addNumbers(10, 5);
```

Conceptually:

```text
10 → firstNumber
5  → secondNumber
```

Then:

```text
firstNumber + secondNumber
       ↓
10 + 5
       ↓
15
```

Notice something important:

The variables:

```java
firstNumber
secondNumber
```

belong to the method.

They are the method's **parameters**.

---

# 11. Why Parameters Are Useful

Without parameters:

```text
displayMaya()
displayAlex()
displayJohn()
```

With parameters:

```text
displayUser("Maya")
displayUser("Alex")
displayUser("John")
```

One method handles multiple situations.

This gives us another level of reuse:

```text
METHOD
  ↓
same responsibility
  ↓
different input
  ↓
different result/action
```
