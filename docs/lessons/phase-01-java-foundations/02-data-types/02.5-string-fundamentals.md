# Lesson 07 — `String` Fundamentals

This is the **last lesson of Topic 2 — Data Types**. After this lesson, we'll move into **Topic 3 — Control Flow**.

## Lesson Objective

By the end of this lesson, you should understand:

* What a `String` represents
* String literals
* How to concatenate strings
* Basic `String` operations
* The difference between `String` and primitive types
* Why `String` is not a primitive type

---

# 1. What Is a `String`?

A `String` represents **text**.

For example:

```java
String name = "Justine";
```

The variable:

```text
name
```

contains the text:

```text
Justine
```

A `String` can contain:

```java
String name = "Justine";
String message = "Hello";
String empty = "";
String sentence = "Java is fun!";
```

It can contain multiple characters.

---

# 2. String Literals

A **String literal** is text written between double quotes:

```java
"Hello"
```

For example:

```java
String language = "Java";
```

The quotes tell Java:

> This is a String literal.

Compare:

```java
char letter = 'A';
String word = "A";
```

They look similar, but they are different types:

```text
'A' → char
"A" → String
```

Remember:

```text
char   → single character
String → text / sequence of characters
```

---

# 3. `String` Is Not a Primitive

This is an important concept.

The primitive types you've learned include:

```text
byte
short
int
long
float
double
char
boolean
```

`String` is **not** one of them.

Instead, `String` is a **class provided by Java**.

You don't need to understand classes deeply yet. That comes later.

For now, remember:

```text
Primitive types:
int
double
boolean
char
...

Reference type:
String
```

So:

```java
int age = 25;
```

uses a primitive type.

While:

```java
String name = "Justine";
```

uses a reference type.

---

# 4. Why Does `String` Start With a Capital S?

Notice:

```java
String name = "Justine";
```

`String` starts with a capital letter.

Compare:

```java
int
double
boolean
char
```

These are primitive type keywords and are lowercase.

`String` is a class name, following Java's naming convention for classes.

For now:

```text
int       → primitive
double    → primitive
boolean   → primitive
char      → primitive
String    → class/reference type
```

---

# 5. String Concatenation

One of the most useful things you can do with Strings is **concatenation**.

Concatenation means joining text together.

For example:

```java
String firstName = "John";
String lastName = "Smith";

String fullName = firstName + lastName;
```

The result is:

```text
JohnSmith
```

Notice there isn't a space.

To include a space:

```java
String fullName = firstName + " " + lastName;
```

Result:

```text
John Smith
```

---

# 6. `+` With Strings

You've already used this:

```java
System.out.println("Age: " + age);
```

Suppose:

```java
int age = 25;
```

Java produces:

```text
Age: 25
```

The `+` is doing concatenation because one side is a `String`.

Conceptually:

```text
"Age: " + 25
     ↓
"Age: 25"
```

---

# 7. String + String

```java
String first = "Java";
String second = "Programming";

System.out.println(first + second);
```

Output:

```text
JavaProgramming
```

Add a space:

```java
System.out.println(first + " " + second);
```

Output:

```text
Java Programming
```

---

# 8. String + Number

This is particularly useful.

```java
int age = 25;

System.out.println("Age: " + age);
```

Output:

```text
Age: 25
```

Java converts the numeric value into text as part of the concatenation.

You can also do:

```java
double price = 1499.99;

System.out.println("Price: " + price);
```

Output:

```text
Price: 1499.99
```

---

# 9. Be Careful With `+`

Consider:

```java
System.out.println(10 + 5);
```

Result:

```text
15
```

Because both operands are numbers.

But:

```java
System.out.println("Result: " + 10 + 5);
```

Result:

```text
Result: 105
```

Why?

Java evaluates from left to right:

```text
"Result: " + 10
       ↓
"Result: 10"

"Result: 10" + 5
       ↓
"Result: 105"
```

Now compare:

```java
System.out.println("Result: " + (10 + 5));
```

Result:

```text
Result: 15
```

The parentheses force the arithmetic to happen first.

This is a very important connection between **Strings, operators, and expressions**.

---

# 10. Basic String Operations

Strings have operations you can perform on them.

For example:

```java
String name = "Java";
```

You can ask for its length:

```java
name.length()
```

Result:

```text
4
```

Why?

```text
J a v a
1 2 3 4
```

So:

```java
System.out.println(name.length());
```

prints:

```text
4
```

We'll study `length()` in much more detail later in **Topic 6 — Strings**.

For now, you only need to understand that Strings provide operations through methods.

---

# 11. `length()`

Example:

```java
String message = "Hello";

System.out.println(message.length());
```

Output:

```text
5
```

The method call:

```java
message.length()
```

means:

> Ask this String for its length.

You don't need to understand methods deeply yet. That's Topic 4.

---

# 12. Empty Strings

This is valid:

```java
String text = "";
```

This is called an **empty String**.

Its length is:

```java
text.length()
```

which produces:

```text
0
```

An empty String is different from `null`.

We'll encounter `null` later, so don't worry about it yet.

---

# 13. Strings Can Contain Numbers

This:

```java
String number = "123";
```

does **not** mean the number 123 mathematically.

It means the text:

```text
"123"
```

Compare:

```java
int number = 123;
```

and:

```java
String number = "123";
```

The first is a number.

The second is text.

This difference becomes extremely important when processing user input.

---

# 14. `"123" + "456"`

Because these are Strings:

```java
String a = "123";
String b = "456";

System.out.println(a + b);
```

Output:

```text
123456
```

It does **not** calculate:

```text
579
```

because Java is joining text.

---

# 15. `123 + 456`

But:

```java
int a = 123;
int b = 456;

System.out.println(a + b);
```

produces:

```text
579
```

So:

```text
"123" + "456"
     ↓
"123456"

123 + 456
     ↓
579
```

Same characters, completely different types and behavior.

---

# 16. String and `char`

Let's compare:

```java
char letter = 'J';
String name = "Java";
```

A `char` holds one character:

```text
'J'
```

A `String` can hold multiple characters:

```text
"Java"
```

You can also have:

```java
String singleCharacter = "J";
```

But this is still a `String`, not a `char`.

The quotes determine the literal type:

```text
'J' → char
"J" → String
```

---

# 17. Important Mental Model

Think of these as different categories:

```text
int
 ↓
number

double
 ↓
decimal number

boolean
 ↓
true / false

char
 ↓
one character

String
 ↓
text
```

This distinction will become extremely important when we start accepting **user input**.
