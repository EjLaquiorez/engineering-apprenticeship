# Lesson 05 — `char` and `boolean`

## Objective

By the end of this lesson, you should understand:

* What `char` represents.
* The difference between `char` and `String`.
* How characters are represented internally.
* How characters can participate in comparisons.
* What `boolean` represents.
* How boolean expressions produce `true` or `false`.
* Why `boolean` values are fundamental to decision-making.

These two types may look simple, but they become extremely important once we start working with **conditions and control flow**.

---

# Part 1 — `char`

We already saw:

```java
char grade = 'A';
```

The variable:

```text
grade
```

has the type:

```text
char
```

and contains:

```text
'A'
```

A `char` represents a **single UTF-16 code unit**.

For now, think of it as:

> **One character.**

Examples:

```java
char letter = 'A';
char number = '5';
char symbol = '$';
char space = ' ';
```

All of these are valid `char` values.

---

# 1. Single Quotes Matter

A `char` uses **single quotes**:

```java
char letter = 'A';
```

A `String` uses **double quotes**:

```java
String letter = "A";
```

These are different types.

```text
'A'
 ↓
char

"A"
 ↓
String
```

Even though they appear visually similar.

---

# 2. One Character vs Multiple Characters

This works:

```java
char letter = 'A';
```

This does not:

```java
char name = 'John';
```

Why?

Because:

```text
'A'     → one character
'John'  → four characters
```

A `char` can hold only one UTF-16 code unit.

If you want multiple characters:

```java
String name = "John";
```

We'll study `String` separately later.

---

# 3. A `char` Can Contain a Digit Character

Consider:

```java
char number = '5';
```

This is valid.

But don't confuse:

```java
char a = '5';
```

with:

```java
int b = 5;
```

They represent different things.

```text
'5'
 ↓
character "5"

5
 ↓
numeric value five
```

This distinction is extremely important.

For example:

```java
System.out.println('5');
```

prints:

```text
5
```

But the value is still a `char`.

---

# 4. Characters Have Numeric Values

Java's `char` is based on UTF-16.

Characters have numeric code values.

For example:

```text
'A' → 65
'B' → 66
'C' → 67
```

So Java can perform arithmetic involving `char`.

Consider:

```java
char letter = 'A';

System.out.println(letter + 1);
```

The result is:

```text
66
```

Why?

Because Java promotes the `char` to an integer for the arithmetic operation:

```text
'A'
 ↓
65
 ↓
65 + 1
 ↓
66
```

This is a preview of **numeric promotion**.

---

# 5. Converting a `char` to an `int`

You can explicitly see the numeric value:

```java
char letter = 'A';

int number = letter;

System.out.println(number);
```

Output:

```text
65
```

Java allows this because `char` has an integral numeric representation.

---

# 6. Converting an `int` to a `char`

Going the other direction requires a cast in general:

```java
int number = 65;

char letter = (char) number;

System.out.println(letter);
```

Output:

```text
A
```

You don't need to memorize casting deeply yet. We'll have a dedicated lesson for it.

For now, understand the relationship:

```text
'A' ↔ 65
'B' ↔ 66
'C' ↔ 67
```

---

# Part 2 — `boolean`

Now let's look at:

```java
boolean active = true;
```

A `boolean` represents a logical value.

There are only two:

```text
true
false
```

That's it.

---

# 7. Boolean Variables

Examples:

```java
boolean active = true;
boolean loggedIn = false;
boolean paid = true;
boolean available = false;
```

These variables describe **states**.

For example:

```text
loggedIn
    ↓
true / false

paid
    ↓
true / false

available
    ↓
true / false
```

---

# 8. Boolean Expressions

A boolean doesn't have to be assigned directly.

We can create one from a comparison.

For example:

```java
int age = 25;

boolean isAdult = age >= 18;
```

What happens?

Java evaluates:

```text
25 >= 18
```

The result is:

```text
true
```

So:

```text
isAdult → true
```

This is extremely important.

A comparison produces a **boolean value**.

---

# 9. Comparison Operators

Here are some operators you'll soon use constantly:

```text
==    equal to
!=    not equal to
>     greater than
<     less than
>=    greater than or equal to
<=    less than or equal to
```

Examples:

```java
int age = 25;

System.out.println(age == 25);
System.out.println(age > 18);
System.out.println(age < 18);
```

Results:

```text
true
true
false
```

Because:

```text
25 == 25 → true
25 > 18  → true
25 < 18  → false
```

---

# 10. `=` vs `==`

This is one of the most important beginner distinctions.

### Assignment

```java
age = 25;
```

Means:

> Put the value `25` into `age`.

### Comparison

```java
age == 25
```

Means:

> Is `age` equal to `25`?

So:

```text
=   → assignment
==  → comparison
```

Don't confuse them.

---

# 11. More Comparisons

Suppose:

```java
int score = 80;
```

Then:

```java
score >= 60
```

produces:

```text
true
```

Because:

```text
80 >= 60
```

But:

```java
score < 60
```

produces:

```text
false
```

This is the foundation of program decision-making.

---

# 12. Comparing Characters

Characters can also be compared.

Consider:

```java
char grade = 'A';

System.out.println(grade == 'A');
```

Result:

```text
true
```

You can also compare their numeric ordering:

```java
System.out.println('A' < 'B');
```

Result:

```text
true
```

Because:

```text
'A' → 65
'B' → 66
```

So Java can determine that:

```text
65 < 66
```

---

# 13. Boolean Logic Preview

You can combine boolean expressions.

For example:

```java
int age = 25;

boolean condition = age >= 18 && age <= 60;
```

The `&&` means **AND**.

Both conditions must be true:

```text
age >= 18
   AND
age <= 60
```

For `age = 25`:

```text
true && true
     ↓
   true
```

We'll study boolean logic in much more depth later.

---

# 14. Another Example

```java
int age = 15;

boolean adult = age >= 18;

System.out.println(adult);
```

Output:

```text
false
```

Notice what's happening:

```text
age
 ↓
15

age >= 18
 ↓
false

adult
 ↓
false
```

This is the beginning of writing programs that can **make decisions based on data**.
