# Lesson 03 — Primitive Data Types

## Objective

By the end of this lesson, you should be able to:

* Explain what a data type is.
* Identify Java's 8 primitive data types.
* Understand what each primitive type is designed to represent.
* Choose an appropriate primitive type for a value.
* Recognize invalid type/value combinations.

The goal is **understanding**, not memorizing a table.

---

# 1. Why Do We Need Data Types?

Consider:

```java
int age = 25;
```

We already learned that:

```text
int   → type
age   → variable name
25    → value
```

But why does Java need `int`?

Because Java needs to know **what kind of data the variable is supposed to contain**.

Compare:

```java
int age = 25;
double price = 19.99;
boolean loggedIn = true;
char grade = 'A';
```

These values represent fundamentally different kinds of information.

```text
25       → whole number
19.99    → decimal number
true     → true/false state
'A'      → single character
```

The data type tells Java how to interpret the value.

---

# 2. Java's 8 Primitive Types

Java has **8 primitive data types**:

```text
byte
short
int
long
float
double
char
boolean
```

We can organize them into groups:

```text
Primitive Types
│
├── Integer types
│   ├── byte
│   ├── short
│   ├── int
│   └── long
│
├── Floating-point types
│   ├── float
│   └── double
│
├── Character type
│   └── char
│
└── Boolean type
    └── boolean
```

---

# 3. Integer Types

Integer types represent **whole numbers**.

For example:

```text
-100
-5
0
10
25
1000
```

They do **not** represent fractional values such as:

```text
3.14
19.99
0.5
```

Java provides four integer types.

---

## `byte`

```java
byte temperature = 25;
```

`byte` uses **8 bits**.

Its range is:

```text
-128 to 127
```

So:

```java
byte x = 100;   // ✅
byte y = 127;   // ✅
byte z = 128;   // ❌
```

For ordinary application code, you won't commonly choose `byte` just because a number happens to be small.

---

# 4. `short`

```java
short population = 30000;
```

`short` uses **16 bits**.

Range:

```text
-32,768 to 32,767
```

Again, it's a valid integer type, but `short` isn't usually the default choice for ordinary Java application variables.

---

# 5. `int`

This is the integer type you'll use most often.

```java
int age = 25;
int score = 100;
int quantity = 50;
```

`int` uses **32 bits**.

Range:

```text
-2,147,483,648
to
2,147,483,647
```

For normal whole-number values, `int` should generally be your default unless you have a reason to use another type.

---

# 6. `long`

`long` uses **64 bits**.

It can represent much larger whole numbers.

```java
long population = 8000000000L;
```

Notice the `L`.

```java
8000000000L
```

The `L` tells Java that this integer literal should be treated as a `long`.

For example:

```java
long distance = 9000000000L;
```

---

# 7. Floating-Point Types

Now consider:

```java
double price = 19.99;
```

`19.99` isn't a whole number.

We need a type capable of representing fractional values.

Java provides:

```text
float
double
```

---

# 8. `double`

`double` is the normal choice for general floating-point calculations.

```java
double price = 19.99;
double temperature = 36.5;
double average = 87.25;
```

For example:

```java
double result = 10.0 / 3.0;
```

The result is approximately:

```text
3.3333333333333335
```

Notice that floating-point numbers are **approximations**, not arbitrary-precision decimal numbers.

This becomes important later when we discuss money and numerical precision.

---

# 9. `float`

`float` also represents floating-point numbers, but with less precision than `double`.

Example:

```java
float temperature = 36.5f;
```

Notice the:

```text
f
```

Why?

Because decimal literals such as:

```java
36.5
```

are treated as `double` by default.

So this:

```java
float temperature = 36.5;
```

❌ doesn't compile.

This:

```java
float temperature = 36.5f;
```

✅ does.

For normal Java application development, **prefer `double` unless you specifically need `float`**.

---

# 10. `char`

`char` represents a **single UTF-16 code unit**.

Example:

```java
char grade = 'A';
char firstLetter = 'J';
char symbol = '$';
```

Notice the single quotes:

```java
'A'
```

Not:

```java
"A"
```

Single quotes are used for `char`.

Double quotes are used for `String`.

```java
char letter = 'A';       // char
String name = "Justine"; // String
```

We'll study `String` in much greater detail later.

---

# 11. `boolean`

A `boolean` represents a logical state:

```text
true
false
```

Example:

```java
boolean loggedIn = true;
boolean isAdult = false;
boolean accountActive = true;
```

Only two values are possible:

```java
true
false
```

You cannot do:

```java
boolean active = 1;
```

❌

Java does not treat `1` and `0` as boolean values like some other languages do.

---

# 12. The Complete Picture

Here's the basic reference:

| Type      | Category  | Example                 |
| --------- | --------- | ----------------------- |
| `byte`    | Integer   | `byte x = 10;`          |
| `short`   | Integer   | `short x = 1000;`       |
| `int`     | Integer   | `int x = 25;`           |
| `long`    | Integer   | `long x = 9000000000L;` |
| `float`   | Decimal   | `float x = 3.14f;`      |
| `double`  | Decimal   | `double x = 3.14;`      |
| `char`    | Character | `char x = 'A';`         |
| `boolean` | Logical   | `boolean x = true;`     |

---

# 13. The Important Engineering Question

Don't ask:

> "Which type do I memorize for this particular example?"

Instead ask:

> **"What kind of data am I representing, and what range/precision does it require?"**

For example:

```text
Age
↓
whole number
↓
int
```

```text
Temperature
↓
fractional number
↓
double
```

```text
Account active?
↓
true/false
↓
boolean
```

```text
Grade letter
↓
single character
↓
char
```

# 14. Let's Test Your Mental Model

Consider:

```java
int age = 25;
double height = 1.75;
boolean student = true;
char grade = 'A';
```

Think about what Java knows:

```text
age
├── type: int
└── value: 25

height
├── type: double
└── value: 1.75

student
├── type: boolean
└── value: true

grade
├── type: char
└── value: 'A'
```

The **type constrains what values can be assigned**.

For example:

```java
int age = 25;
age = 30;       // ✅

age = 30.5;     // ❌
age = true;     // ❌
age = 'A';      // ❌
```

This is one of the major benefits of Java's static type system.
