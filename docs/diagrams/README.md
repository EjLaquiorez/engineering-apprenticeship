# Diagrams

Architecture diagrams, sequence diagrams, entity-relationship diagrams, and flowcharts.

## Conventions

- Use Mermaid (`.md` files) or draw.io (`.drawio`) for version-controlled diagrams
- Name files descriptively: `user-auth-sequence.md`, `order-entity-relationship.md`
- Reference diagrams from project `docs/architecture.md` files

## Subdirectories

Create topic-specific folders as needed:

```text
diagrams/
├── system-overview/
├── sequence-diagrams/
└── entity-relationship-diagrams/
```
