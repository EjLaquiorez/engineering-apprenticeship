# Documentation

All theoretical material for the Engineering Apprenticeship Program—kept separate from implementation in `projects/`.

## Directories

| Directory | Contents |
|-----------|----------|
| [program/](program/) | Mentor framework, engineering cycle, apprenticeship rules |
| [lessons/](lessons/) | Phase 0–10 guided learning paths |
| [notes/](notes/) | Personal study notes |
| [references/](references/) | Books, articles, external links |
| [diagrams/](diagrams/) | Architecture, sequence, and ERD diagrams |
| [cheatsheets/](cheatsheets/) | Quick-reference guides |

## Rules

- Never mix documentation with source code in `projects/*/src/`
- Use `kebab-case` for all folder and file names
- Log evidence of learning in `progress/evidence-log.md`, not in lesson folders
