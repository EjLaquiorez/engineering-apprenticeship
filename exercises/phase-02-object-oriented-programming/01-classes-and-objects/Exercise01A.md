### Exercise 01A — Identify Objects

We’re correcting the sequence first, so **Exercise 01A comes before the Lesson 02 exercises**.

### Goal

Practice identifying **objects** in the real world and separating:

* **Identity** — what the thing is
* **Data** — information/characteristics it has
* **Behavior** — things it can do

You already did this conceptually when you said:

> data → brand, color, speed, model
> behavior → start, accelerate, ...

That's exactly the kind of thinking we're practicing.

### Exercise 01A — Identify Objects

```text
Object: Dog
Identity: A specific dog

Data:
1. Name
2. Breed
3. Age

Behavior:
1. Bark
2. Eat
3. Run
```

The important idea is:

* **Object:** `Dog`
* **Data:** describes the dog → `name`, `breed`, `age`
* **Behavior:** what the dog can do → `bark()`, `eat()`, `run()`

This is the thinking we'll later translate into a Java class:

```text
Dog
├── Data
│   ├── name
│   ├── breed
│   └── age
│
└── Behavior
    ├── bark()
    ├── eat()
    └── run()
```
